A run, start to finish.

You do not call skills by name. You describe the outcome, the agent matches your request against the one-line descriptions, and it loads the body of the skill it picks. Here is that loop with suede-visibility-grader, using the real lanes defined in its SKILL.md.

claude code · what you type 
> grade my landing page before I launch it
> https://example.com/pricing
1 · RouteNo skill name required. The description “grade a public page for launch appeal” matches, so the agent loads that one folder. Every other skill stays on disk.
2 · InspectThe skill forbids grading from memory. It pulls the live URL, status code, canonical, robots, sitemap, rendered first viewport, headings, CTAs, Open Graph, and JSON-LD before scoring anything.
3 · ScoreFive lanes, each graded A–F from inspection evidence and mechanical caps, never impression or generosity, then one overall grade.
4 · Hand backA grade per lane, the evidence behind each, and the ranked fixes. The verdict is advice: a failed gate changes what the agent reports, never what it does.

Use it before the page goes public.

In the minute before you publish, the page gets a letter. The first-screen lane asks three questions: who this is for, what changes for them, and what to do now. A first viewport that answers none of them takes the whole grade down with it.

Before redesignPoint Suedify at the reference site and it maps that design grammar onto the target. The reference lends its structure. It does not lend its logo or its claims.
Before publishing docsRun the install command yourself, from a clean directory, and open the page on a phone. A doc that publishes a command nobody ran is a guess with good typography.
Before launchGrade the page first, then fix only the lane that failed. The ranked fixes arrive with the evidence behind each one, so you are not guessing at which change moved the letter.
Before the next passTell the agent what looked right and what missed, or say Cue Suede to preserve the preference, revise the output, or keep the pass as-is.
Before handoffAgent-team loops scout first, split lanes that do not touch the same files, and review each other adversarially. The record at the end names the files, the commands, and every caveat that was not dropped to make it look clean.

From folder to evidence package.

The five creator skills start from a local folder and end with an organized evidence package for review. Reports stay local; nothing is uploaded or cleared.

1 · InspectWalk the folder as it stands and write down what is in it, down to the stems and the loose documents.
2 · LintA bundled offline script scores the folder and marks every fact present, missing, or unknown. Unknown never gets upgraded to confirmed.
3 · ConfirmOnly the creator moves a fact from unknown to confirmed. The skill asks the question and records the answer.
4 · PackageThe package is written to your machine. Legal, registry, and payout claims stay out of the report.

Suede workflow FAQ.

Four answers for the developer deciding whether to install this before the next diff.

What are Suede Creator Skills?

Suede Creator Skills are free, open-source SKILL.md folders for Claude Code and OpenAI Codex. Original work is MIT licensed, and adapted components retain their upstream notices. The range runs from an A to F review of a staged diff to an Amazon chat window that argued $448.31 back. One of those recoveries was a refund already denied after the return window closed.

Does this work with my agent?

Claude Code and Codex each install with two commands. For anything else, npx skills add JasonColapietro/suede-creator-skills drops the same folders into Cursor, Copilot, or Windsurf. The files are identical on every surface, because there is only one copy of them.

When should I use Agent Teams?

When two agents are about to edit the same file and neither of them knows it. Agent Teams maps file ownership before anyone opens anything, and sequences the lanes that collide. The handoff is held until the evidence is attached, so done means something.

Do the skills copy websites exactly?

No. Suedify studies layout, rhythm, typography, color roles, motion, and proof structure, then recreates the design grammar with target-owned content and assets.
