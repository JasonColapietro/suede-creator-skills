Public installs and MCP

Install Suede once. Stop rebuilding the agent brief.

Public skills your agent can load as one workflow. Use Suede Ship for broad, authorized outcomes that need one controller, useful non-colliding lanes, adversarial review, and proof. Install the umbrella to Suedify a target page from a reference URL, rewrite copy, grade visibility, review code A-F, design AI evals, run Instagram growth, ship an iOS or Android app, coordinate agent teams, or package creator campaign and rights evidence. Use MCP when the agent needs structured discovery, install options, audit scaffolds, or QA checklists.

Which install is yours Skill contracts align; runner capabilities differ

Claude Code: two lines

Add the marketplace, install the pack. suede-skills installs every skill.

claude code 
/plugin marketplace add JasonColapietro/suede-creator-skills
/plugin install suede-skills@suede

Want less than the full pack? Three focused subsets install the same way: /plugin install suede-marketing@suede (42 skills: paid acquisition, outbound, pricing, offers, lifecycle, Instagram growth, AI search optimization, attribution, and analytics), /plugin install suede-agent-workflows@suede (orchestration, workflows, evals), or /plugin install suede-code@suede (review, grade, ship-gate).

Prefer a clone? install.sh copies every skill into ~/.claude/skills/ and never touches skills that are not part of the pack:

shell 
git clone https://github.com/JasonColapietro/suede-creator-skills.git && bash suede-creator-skills/install.sh

Using Cursor, Copilot, Windsurf, or another agent? The open skills CLI installs the pack into its supported agents, Claude Code and Codex included:

These routes install the portable skill contracts. Suede Ship's executable Graph-of-Thoughts workflow additionally requires Claude Code on macOS plus its six registered suede-ship-* agent profiles. The full Claude Code plugin, the suede-agent-workflows subset, and install.sh register those profiles. Codex and generic skills-CLI installs can follow the contract through direct implementation, but do not execute the bundled Claude Workflow.

any agent 
npx skills add JasonColapietro/suede-creator-skills

For a project-level copy of a single skill in Claude Code: cp -R suede-creator-skills/skills/<name> .claude/skills/. A single-folder copy of Suede Ship installs its orchestration contract only. To run its bundled workflow, also copy agents/suede-ship-*.md into ~/.claude/agents/ and restart Claude Code.

Codex: install the pack or pick your set

The Codex-native plugin installs every skill contract and registers three read-only MCP discovery profiles. It does not execute Suede Ship's bundled Claude Workflow. Add the repo marketplace, install the pack, then restart Codex.

codex plugin 
codex plugin marketplace add JasonColapietro/suede-creator-skills --ref main
codex plugin add suede-skills@suede-codex

Want only selected skills? Codex can also install any public skill folder from GitHub. Direct skill installs land in ~/.codex/skills (or $CODEX_HOME/skills).

The Suede Skills MCP

A dependency-free stdio MCP server ships in the repo at mcp/. Run it when the agent needs structured discovery, install options, audit scaffolds, or QA checklists.

mcp server 
node mcp/suede-skills-mcp.mjs --profile all

Profiles: all, the bundle areas workflow, marketing, creator, consumer, or any one specialty — ship, craft, found, demand, revenue, position. It implements initialize, tools/list, tools/call, resources/list, resources/read, prompts/list, and prompts/get: 9 tools, 7 resources, 5 prompts. No dependencies, no network calls, no install step beyond running the file.

The MCP surface One process, five profiles, zero dependencies

The 9 tools

list_suede_specialtiesLists the six specialities, their sub-lanes, and skill counts. Call it first to pick a specialty, then filter with it.
list_suede_skillsLists Suede skills, optionally narrowed to one bundle area or one specialty.
search_suede_skillsRanks the pack against a task description and returns the best-matching skills instead of the whole pack.
get_suede_skillReturns one skill description and when to use it, or the full SKILL.md with includeBody.
suede_install_optionsReturns public skill, MCP, local plugin, and skill-copy install options.
suede_copy_seo_auditBuilds an SEO/AEO/AI EO copy audit scaffold with metadata, schema, CTA, proof, and verification checks.
suede_visibility_gradeBuilds an A-F visibility and CTA grading scaffold: findability, first-screen clarity, proof, AI readability, design signal, grade caps, ship readiness.
suede_code_gradeBuilds an A-F code grading scaffold: correctness, security, data/state, UX and release behavior, tests, deploy readiness, required upgrades.
suede_qa_checklistBuilds a multi-lane QA checklist for MCP, skills, docs, local plugin notes, and public site work.

What it adds in practice

Skill discoveryAgents search or ask for the right Suede skill for Suedify, design, copy, SEO/AEO/AI EO, QA, artist campaigns, or utilities instead of guessing from memory.

Grading scaffoldsVisibility and code checks route through focused A-F graders with evidence requirements instead of vibes.
QA loopsFull QA passes for skills, MCP, docs, public site changes, and adversarial review loops.
