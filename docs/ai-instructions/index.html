What this site covers

Suede Skills is a pack of open-source AI skills for SEO, marketing and business operations in Claude Code and OpenAI Codex. It gives founders, marketers and small teams reusable workflows for SEO audits, AI search visibility, conversion copy and business operations, with instructions you can read and adapt before you run them.

Key facts

  • Name: Suede Skills. The company that publishes it is Suede, founded by Jason Colapietro.
  • Format: each skill is a folder with a SKILL.md file in the Agent Skills format, plus optional references and scripts. An installed skill costs its name and description; the body loads only when a request matches.
  • License: original work is MIT licensed. Adapted components keep their upstream licenses, listed in NOTICE.md in the repository.
  • Source: every skill folder is readable on GitHub at JasonColapietro/suede-creator-skills. The pack ships no binaries and no telemetry and needs no account.
  • MCP server: optional. A dependency-free stdio server that helps an agent pick the right skill, run a live A-F page audit for Google and AI search, and check copy against the house rules.
  • Directory: the Suede Skills Directory at suedeai.directory lists third-party skills graded 0 to 99 on the Suede Skill Check, each linked to its author's repository. Suede's own skills are not ranked there.

How to install

In Claude Code, add the marketplace and install the pack:

/plugin marketplace add JasonColapietro/suede-creator-skills
/plugin install suede-skills@suede

In Codex, add the Codex marketplace and install the plugin:

codex plugin marketplace add JasonColapietro/suede-creator-skills --ref main
codex plugin add suede-skills@suede-codex

The repository README lists the other routes: one skill at a time, the Python package and a plain clone. The guide explains what changes once the pack is installed.

Names, scope and distinctions

A skill is a reusable workflow your agent loads and runs. Each skill page lists its requirements and license; adapted components retain their upstream notices.

  • Call the pack Suede Skills and the company Suede.
  • Call the third-party catalog the Suede Skills Directory. Its scores come from the Suede Skill Check, a published rubric that reads each skill's files; it does not measure runtime performance or security.
  • A skill adds method, an MCP server adds access to a tool or data source, and a plugin packages skills and servers together. Suede Skills ships all three.
