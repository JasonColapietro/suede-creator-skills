# Suede SEO workflow crosswalk

This evaluation covers all 30 workflows in [Illyism/seo-skills by Ilias Ism](https://github.com/Illyism/seo-skills/tree/88b0052369cecca1bb2edac5d917c598e4e78363). The pinned upstream [README declares MIT](https://github.com/Illyism/seo-skills/blob/88b0052369cecca1bb2edac5d917c598e4e78363/README.md#license). The contributions below are independently written. Existing Suede skills absorb overlaps; a new skill is added when the work product and trigger are distinct. No upstream executable or external service is bundled.
