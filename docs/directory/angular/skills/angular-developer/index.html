Generates Angular code and provides architectural guidance. Install angular-developer

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/angular/skills --skill angular-developer

Claude Code, project-level copy:

git clone --depth 1 https://github.com/angular/skills.git /tmp/skills
mkdir -p .claude/skills
cp -R /tmp/skills/angular-developer .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo angular/skills \
    --path angular-developer
