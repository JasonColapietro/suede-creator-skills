How skills are listed and graded

Directory / Methodology

The directory lists public Agent Skills that pass a published, mechanical check. This page is the whole method: where skills come from, what is checked, what gets a page of its own, and how to change a listing.

Where the skills come from

The directory reads the repositories cited by at least two of these 8 curated lists: BehiSecc/awesome-claude-skills, ComposioHQ/awesome-claude-skills, VoltAgent/awesome-agent-skills, heilcheng/awesome-agent-skills, hesreallyhim/awesome-claude-code, karanb192/awesome-claude-skills, skillmatic-ai/awesome-agent-skills, travisvn/awesome-claude-skills. It adds the official collections those lists name and repositories accepted through listing requests. Every SKILL.md in those repositories is read from the default branch, and nothing in them is executed. This snapshot was taken on October 16, 2026.

The Suede Skill Check

Eight checks: six on the SKILL.md format, following the Agent Skills format, plus a declared license and a commit in the last year. The first check is required; the grade counts the other seven.

The check confirms a skill is well-formed, licensed and maintained. Read its SKILL.md to confirm it fits your task.

Listing rules

  • Grade A or B on the Suede Skill Check.
  • A license declared in the SKILL.md frontmatter or the repository. Every page states it; 97% of listed skills use an open-source or open-content license, and pages for the rest say what their terms allow.
  • A description written mainly in English, so the directory's pages read consistently.
  • Templates, examples, drafts and test fixtures are skipped.
  • One listing per skill. A copy is the same skill name with a mostly matching description, or a description repeated word for word under another name. When copies appear in several repositories, the copy in the repository cited by the most lists keeps the listing.
  • Skills are not listed when they:
    • automate posting, messaging or account activity on a social platform;
    • work around a site's blocks, CAPTCHAs or official API;
    • have scraping a third-party site as their main job (a vendor's skills for its own service are listed);
    • look up an individual's email address, phone number or personal profiles.

Which skills get a full page

Every listed skill appears in its category directory and on its repository's page. Grade A skills get a page of their own, up to twelve per repository, chosen by how much ships with the skill: reference files, scripts, assets and a structured SKILL.md. Each page carries a one-sentence summary written by the directory, a pre-install summary of the scripts, credentials and network calls found in the skill's files, install steps, and a README badge. 738 skills have a full page in this snapshot. A repository with a single listed skill is listed through that skill's page.

Categories

Categories group skills by their main task, so you can compare alternatives side by side. Each skill sits in one of 16 categories, assigned from its name and description.

Refreshes and changes

Each refresh re-reads the source repositories, so quoted descriptions, file facts and check results follow the published SKILL.md. To request a listing, a correction or a removal, use the listing request page; requests are reviewed by hand.

The Suede Skill Check reads published SKILL.md files and the files beside them. It executes nothing.
