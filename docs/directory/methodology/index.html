Suede Skills Directory · Method

How skills are listed and graded

Directory / Methodology

The directory lists public Agent Skills that pass a published, mechanical check. This page is the whole method: where skills come from, what is checked, what gets a page of its own, and how to change a listing.

Where the skills come from

The directory starts from the repositories cited in 8 curated lists of agent skills: BehiSecc/awesome-claude-skills, ComposioHQ/awesome-claude-skills, VoltAgent/awesome-agent-skills, heilcheng/awesome-agent-skills, hesreallyhim/awesome-claude-code, karanb192/awesome-claude-skills, skillmatic-ai/awesome-agent-skills, travisvn/awesome-claude-skills, plus the official skill collections those lists name. Every SKILL.md file in those repositories is read from the default branch. Nothing is executed. The current snapshot was taken on October 16, 2026.

The Suede Skill Check

Eight checks against the Agent Skills format. The first is required; the grade counts the other seven.

  • Grade A: all seven graded checks pass (2,035 listed skills).
  • Grade B: six of seven pass (990 listed skills).
  • Grades C and below are not listed.

The check measures structure, not usefulness: a well-formed skill can still be the wrong tool for your task. Read the SKILL.md before you install.

Listing rules

  • Grade A or B on the Suede Skill Check.
  • A license declared in the SKILL.md frontmatter or the repository. Every page states it; 97% of listed skills use an open-source or open-content license, and pages for the rest say so next to the license.
  • A description written mainly in English, so the directory's pages read consistently.
  • Templates, examples and test fixtures are skipped.
  • When the same skill (same name and description) appears in several repositories, the copy in the most-cited repository is listed and the copies are dropped, so the original author keeps the listing.
  • Skills built for scraping, evading platform rules or adult content are not listed.

Which skills get a full page

Every listed skill appears on its repository's page and in its category directory. Grade A skills get a page of their own with install commands, the check results and a README badge, up to twelve per repository, chosen by how much the skill ships with it: reference files, scripts, assets and a structured SKILL.md. 740 skills have a full page in this snapshot.

Categories

Each skill sits in one of 16 categories, chosen from its name and description by what the skill is mainly for. A category is a browsing aid, not a claim about the author's intent.

Changing a listing

The directory is rebuilt from the source repositories. Push a change to your SKILL.md and it appears at the next refresh. To request a listing, a correction or a removal, use the listing request page.

The Suede Skill Check is a structural check of public SKILL.md files. It runs on published files only and executes nothing.
