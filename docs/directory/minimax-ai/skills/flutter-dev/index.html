Install flutter-dev

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/minimax-ai/skills --skill flutter-dev

Claude Code, project-level copy:

git clone --depth 1 https://github.com/minimax-ai/skills.git /tmp/skills
mkdir -p .claude/skills
cp -R /tmp/skills/skills/flutter-dev .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo minimax-ai/skills \
    --path skills/flutter-dev
