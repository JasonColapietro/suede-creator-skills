Install flutter-dev

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/MiniMax-AI/skills/tree/main/skills/flutter-dev

tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/MiniMax-AI/skills.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/flutter-dev .claude/skills/
rm -rf "$tmp"
Codex installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
