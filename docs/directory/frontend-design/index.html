How to choose frontend and design skills

Choose one design skill as the source of visual rules. Several design skills set strong opinions on type, color and spacing, and stacking two produces mixed results.

Framework skills (React, Angular, Flutter and others) belong with your stack; design skills sit above them and work across frameworks.

Ask for screenshots or renders as output. Skills that verify their own UI in a browser catch layout problems before you review.
