How the author describes it

Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can...", or express interest in extending capabilities. This skill should be used when the user is looking for functionality that might exist as an installable skill.

From the description field of SKILL.md. Agents read this line to decide when to load the skill.

Install find-skills

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/vercel-labs/skills --skill find-skills

Claude Code, project-level copy:

git clone --depth 1 https://github.com/vercel-labs/skills.git /tmp/skills
mkdir -p .claude/skills
cp -R /tmp/skills/skills/find-skills .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo vercel-labs/skills \
    --path skills/find-skills

vercel-labs/skills is third-party code. Suede lists it and links to the source; read SKILL.md and any bundled scripts before you install it.
