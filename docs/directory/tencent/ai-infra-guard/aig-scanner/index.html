Install aig-scanner

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/Tencent/AI-Infra-Guard/tree/main/skills/aig-scanner
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/Tencent/AI-Infra-Guard.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/aig-scanner .claude/skills/
rm -rf "$tmp"
Codex, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/Tencent/AI-Infra-Guard.git "$tmp/repo"
mkdir -p .agents/skills
cp -R "$tmp/repo/"skills/aig-scanner .agents/skills/
rm -rf "$tmp"

For a user-level install, copy the folder to ~/.claude/skills/ (Claude Code) or ~/.agents/skills/ (Codex). Inside Codex, $skill-installer can also fetch a skill from GitHub. New to skills? Read How to install agent skills in Claude Code, Codex and Cursor.

How the author describes it

A.I.G Scanner — AI security scanning for infrastructure, AI tools / skills, AI Agents, and LLM jailbreak evaluation via Tencent Zhuque Lab AI-Infra-Guard. Uses built-in exec + Python script, no plugin required. Requires AIG_BASE_URL to be configured. Triggers on: scan AI service, AI vulnerability scan, scan AI infra, check CVE, audit AI service, scan MCP, scan skills, audit AI tools, scan agent, red-team LLM, jailbreak test, 扫描AI服务, 检查AI漏洞, 扫描AI工具, 检查MCP安全, 审计Agent, 越狱测试.
