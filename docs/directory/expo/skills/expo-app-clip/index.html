Install expo-app-clip

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/expo/skills --skill expo-app-clip

Claude Code, project-level copy:

tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/expo/skills.git "$tmp/skills"
mkdir -p .claude/skills
cp -R "$tmp/skills/plugins/expo/skills/expo-app-clip" .claude/skills/
rm -rf "$tmp"

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo expo/skills \
    --path plugins/expo/skills/expo-app-clip

expo/skills is third-party code. Read SKILL.md and any bundled scripts before you install it.

How the author describes it

Add an iOS App Clip target to an Expo app. Use when the user mentions App Clip, AASA, apple-app-site-association, appclips, smart app banner, or wants to ship a lightweight iOS Clip invoked from a URL alongside their parent app.
