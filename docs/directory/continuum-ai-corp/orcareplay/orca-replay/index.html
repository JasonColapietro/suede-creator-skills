How the author describes it

Answers questions about a past agent run from its recording rather than from memory, and replays or forks that run. Use when asked why an earlier run did something, or to reproduce a failure.

From the description field of SKILL.md. Agents read this line to decide when to load the skill.

Install orca-replay

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/continuum-ai-corp/orcareplay --skill orca-replay

Claude Code, project-level copy:

git clone --depth 1 https://github.com/continuum-ai-corp/orcareplay.git /tmp/orcareplay
mkdir -p .claude/skills
cp -R /tmp/orcareplay/skills/orca-replay .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo continuum-ai-corp/orcareplay \
    --path skills/orca-replay
