How the author describes it

Answers questions about a past agent run from its recording rather than from memory, and replays or forks that run. Use when asked why an earlier run did something, or to reproduce a failure.

From the description field of SKILL.md. Agents read this line to decide when to load the skill.

Compatibility, from SKILL.md

CompatibilityRequires the `orcareplay` npm package (Node 20+) with its MCP server registered as `orca`, and at least one recorded run in the project's .orca/runs directory.
