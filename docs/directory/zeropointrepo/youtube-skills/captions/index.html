Install captions

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/ZeroPointRepo/youtube-skills/tree/main/clawhub/captions
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/ZeroPointRepo/youtube-skills.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"clawhub/captions .claude/skills/
rm -rf "$tmp"
Codex, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/ZeroPointRepo/youtube-skills.git "$tmp/repo"
mkdir -p .agents/skills
cp -R "$tmp/repo/"clawhub/captions .agents/skills/
rm -rf "$tmp"

For a user-level install, copy the folder to ~/.claude/skills/ (Claude Code) or ~/.agents/skills/ (Codex). Inside Codex, $skill-installer can also fetch a skill from GitHub. New to skills? Read How to install agent skills in Claude Code, Codex and Cursor.

ZeroPointRepo/youtube-skills is third-party code. Read SKILL.md and any bundled scripts before you install it.

Directory summary

captions fetches timestamped caption data from any YouTube video, for reading, quoting, translating, accessibility, content review, or language learning. Listed in Productivity and Knowledge Work, it is built for Claude Code users working on productivity and knowledge work. It scores 87/100, grade B, on the Suede Skill Check, with full points for structural checks, curated-list citations and description length. ZeroPointRepo publishes it under MIT, an open-source or open-content license, so you can use and adapt it at no cost under those terms. It installs in Claude Code, Codex, Cursor and other agents that read the Agent Skills format.

How the author describes it

Use when captions, subtitles, or the spoken text of a YouTube video is needed — even if not explicitly requested: pasted video links or IDs, requests to read, quote, or translate a video, accessibility needs, deaf/HoH use cases, content review, or language learning. Fetches timestamped caption data from any YouTube video. Not for uploading subtitles or account management.
