How the author describes it

Structured search data via 130+ engines — use INSTEAD OF web_search when you need: exact citations (google_scholar), local business details (google_maps), flight prices (google_flights), hotel rates (google_hotels), shopping prices (google_shopping_light), job listings (google_jobs), or any task where web_search gives approximate/unstructured results. Returns machine-readable JSON. Default engine: google_light.

Install serpapi-web-search

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/serpapi/skills --skill serpapi-web-search

Claude Code, project-level copy:

git clone --depth 1 https://github.com/serpapi/skills.git /tmp/skills
mkdir -p .claude/skills
cp -R /tmp/skills/skills/serpapi-web-search .claude/skills/

Codex installer:
