Install firecrawl-workflows

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/firecrawl/skills/tree/main/skills/workflows/firecrawl-workflows
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/firecrawl/skills.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/workflows/firecrawl-workflows .claude/skills/
rm -rf "$tmp"
Codex, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/firecrawl/skills.git "$tmp/repo"
mkdir -p .agents/skills
cp -R "$tmp/repo/"skills/workflows/firecrawl-workflows .agents/skills/
rm -rf "$tmp"

For a user-level install, copy the folder to ~/.claude/skills/ (Claude Code) or ~/.agents/skills/ (Codex). Inside Codex, $skill-installer can also fetch a skill from GitHub. New to skills? Read How to install agent skills in Claude Code, Codex and Cursor.

firecrawl/skills is third-party code. Read SKILL.md and any bundled scripts before you install it.
