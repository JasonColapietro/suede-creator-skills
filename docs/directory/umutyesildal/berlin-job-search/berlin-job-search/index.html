Install berlin-job-search

Use Python 3.9+ and internet access for the public job-source APIs; the scripts use only the standard library and need no API keys. LinkedIn uses low-volume logged-out guest pages; automated access is against LinkedIn’s User Agreement. Keep CVs, profiles and tracker data locally in job-search/. PDF rendering optionally uses installed Chrome, Chromium or Edge. The repository’s plugin separately declares the Daily Berlin Jobs MCP connector; installing this skill folder alone does not configure that connector. The user controls accounts and submits applications. Publisher setup instructions.

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.
