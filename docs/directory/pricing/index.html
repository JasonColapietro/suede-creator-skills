Directory / Cost and license

Every listed skill is free to download. What it costs to run depends on its license and on the services its files connect to. Four lanes sort all 3,871 listed skills.

Cost and license lanes

Free and open source (3,478)Skills under an open-source or open-content license whose files name no paid service, API key or hosted account. Install them and run them as they are. Free skill, needs a service (287)Skills under an open license whose files read an API key, call an outside host or connect to an MCP server. The skill is free; the service it talks to may not be. Non-commercial license (80)Skills published under a license that allows personal, research or other non-commercial use only. Check the license before using one in paid work. Restricted license (26)Skills whose repository reserves rights, uses a proprietary license or states terms only in a LICENSE file the directory could not classify. Read the terms at the source before installing.

Questions and answers

Are Claude Code skills free?

Every listed skill is published in a public GitHub repository and costs nothing to download. In the October 22, 2026 snapshot, 3,478 use an open license and name no paid service, 287 use an open license but connect to an outside service, 80 allow non-commercial use only and 26 use restricted terms.

How does the directory decide a skill needs a service?

For skills with full pages, from the install record the refresh reads from the skill's files: environment variables, MCP servers, outside hosts and HTTP clients. For other skills, from the compatibility line the author wrote in SKILL.md.

Can I use these skills in commercial work?

Skills under open-source or open-content licenses allow it under their terms. Non-commercial licenses do not, and restricted licenses need the publisher's permission. Each listing links to its license file.
