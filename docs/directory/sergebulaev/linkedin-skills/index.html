linkedin-post-writer 91/100 · A

Publisher's task description: Draft a new LinkedIn post from scratch using one of 20 2026 hook formulas (anaphora, R.I.P., time-anchor, curiosity-gap, contrarian, controlled A/B, false-binary, and more) plus a founders-edition angle library, picked by engagement goal (comments, reposts, likes, saves). Runs the humanizer pass and schedules via Publora on approval. Use to write a post, find a hook or proven format, or get founder-specific angles. Not for reviewing existing drafts (use linkedin-humanizer --mode audit).

linkedin-reply-handler 91/100 · A

Publisher's task description: Draft a reply to one LinkedIn comment from its URL, or sweep a whole thread from just the post URL and draft a reply to every comment worth answering, in one batch. Use for replying to a comment, following an author reply, or clearing all comments on a post. Resolves the correct parentComment (LinkedIn flattens threads to 2 levels), filters low-value comments before a sweep, and posts via Publora on approval. Not for top-level comments (use linkedin-comment-drafter).

  1. Select one skill. Use the folder-specific command beside its description; a whole-repository install can include other files or miss nested skills, so use the listed skill's folder. Skills with publisher-specific license terms link to that publisher's setup route.
  2. Read the setup requirements. Check the source, license and any named tools or environment variables. Installing a SKILL.md folder supplies instructions to the agent; any external CLI, MCP server, account or service still needs its own setup.
  3. Check the result. Open the installed SKILL.md and confirm that its name matches your selection. In Claude Code use the project's .claude/skills/ folder; in Codex use .agents/skills/. The skills CLI also supports other Agent Skills hosts.
  4. Try one representative task. Supply the input files, expected output and success criteria. Compare the result with those criteria before adding more skills or running the workflow on live work.
