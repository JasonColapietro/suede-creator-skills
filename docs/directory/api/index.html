Directory / API and data

Everything the directory publishes is a static file on this host. There is no key, no rate limit and no account; please link back to the listing when you quote a score, and name skills.sh when you quote an install count.

Where install counts come from

The directory does not measure installs. installs.json is a snapshot of counts published by skills.sh, which records installs made with the skills CLI (npx skills add) from anonymous, deduplicated telemetry as its documentation describes. The snapshot was read on November 2, 2026 from its public search endpoint, one query per listed repository, and its home page leaderboard for eight weeks of history. 2,865 listed skills matched; skills without a count are not tracked there. The script is scripts/directory/installs.mjs.

Recomputing a score

Scores are computed only from published fields, so a report can be checked. scripts/directory/badges.mjs and scripts/directory/grade.py in the repository recompute the same value from skills.json; the methodology lists every component and its points.

The directory's data is published as static files. Scores follow the published methodology; install counts are skills.sh's.
