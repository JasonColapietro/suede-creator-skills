Builds, reviews, and measures UI motion, including springs, gestures, scroll effects, curve fitting from recordings, and sparse interface sound. Use when asked to "add animation", "match this easing", "reverse engineer this motion", "add a click sound", or find animation opportunities.

Install ui-animation

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/mblode/agent-skills --skill ui-animation

Claude Code, project-level copy:

git clone --depth 1 https://github.com/mblode/agent-skills.git /tmp/agent-skills
mkdir -p .claude/skills
cp -R /tmp/agent-skills/skills/ui-animation .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo mblode/agent-skills \
