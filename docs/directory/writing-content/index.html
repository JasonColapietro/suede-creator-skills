How to choose writing and editing skills

Editing skills work best on a draft you supply. Give them your text and your audience, and ask for changes with reasons so you can accept them one by one.

Documentation skills follow a house format. Pick one whose structure matches your docs site, or adapt its template once and keep it.

Most writing skills are plain Markdown, so you can read the whole standard in the SKILL.md before you install it; the scripts line on each page shows the ones that bundle code.
