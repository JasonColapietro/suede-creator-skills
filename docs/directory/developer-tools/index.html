How to choose developer tools and frameworks skills

Match skills to the stack you actually ship. A framework skill earns its place by encoding the version-specific rules your agent would otherwise guess at, so prefer one written for the version you run.

Look for the Official tag. Skills published by the company behind a framework or SDK track its current APIs, and the directory tags their collections Official.

Several collections ship one skill per framework task. Installing the whole repository is one command; installing only the skills for your stack keeps the agent's routing list short.
