Install sheetfolk-budget-builder

The local workbook helper requires Python 3 and no third-party packages. At the reviewed revision it overwrites an existing output path and the TOTAL row adds income to outflows. Use an unused output filename and calculate net cash flow separately until upstream PR #1 is accepted. The PR adds exclusive creation, net formulas, and regression tests.
