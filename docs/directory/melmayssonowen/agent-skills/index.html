Install and verify your selection

  1. Select one skill. Use the folder-specific command beside its description; a whole-repository install can include other files or miss nested skills, so use the listed skill's folder. Skills with publisher-specific license terms link to that publisher's setup route.
  2. Read the setup requirements. Check the source, license and any named tools or environment variables. Installing a SKILL.md folder supplies instructions to the agent; any external CLI, MCP server, account or service still needs its own setup.
  3. Check the result. Open the installed SKILL.md and confirm that its name matches your selection. In Claude Code use the project's .claude/skills/ folder; in Codex use .agents/skills/. The skills CLI also supports other Agent Skills hosts.
  4. Try one representative task. Supply the input files, expected output and success criteria. Compare the result with those criteria before adding more skills or running the workflow on live work.
