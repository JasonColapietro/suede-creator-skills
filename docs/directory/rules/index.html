Rules, instruction files and prompts

Directory / Rules, instruction files and prompts

Before an agent loads a skill it reads the instruction files in your repository: AGENTS.md, CLAUDE.md, Cursor rules, Copilot instructions. These collections hold reviewed examples, templates and the standards that define the formats.

  • 18 listed repositories
  • 12 from official publishers
  • 4 sections

AGENTS.md is a plain Markdown file at the repository root that most coding agents read, including Codex, Cursor, Copilot, Gemini CLI, Grok Build and Claude Code when no CLAUDE.md is present. Cursor adds project rules in .cursor/rules as .mdc files with scoping frontmatter; Copilot reads .github/copilot-instructions.md and path-specific instruction files.

Persona files such as SOUL.md and prompt libraries such as Fabric's patterns are the same idea for assistants that live in chat apps: text the agent loads every session. None of these carry code, which makes them the easiest layer to review before you adopt them.

How instruction files install

Copy the file into the place your agent reads. Most of them need no tooling: AGENTS.md goes at the repository root, Cursor rules into .cursor/rules, Copilot instructions into .github, CLAUDE.md beside your code. Plugins for Codex, Cursor and Gemini CLI install with each product's own command.

Commands
codex plugin marketplace add owner/repo
gemini extensions install https://github.com/gemini-cli-extensions/workspace
copilot plugin marketplace add github/awesome-copilot

Questions and answers

What is AGENTS.md?

A plain Markdown file at the repository root with instructions for coding agents, stewarded by the Agentic AI Foundation. Codex, Cursor, Copilot, Gemini CLI and Grok Build read it, and Claude Code reads it when the project has no CLAUDE.md.

Where do Cursor rules go?

Project rules live in .cursor/rules as .mdc files with description, globs and alwaysApply frontmatter. A plain .md file in that folder is ignored. Cursor also reads AGENTS.md at the root and in subfolders.

Do these files run code?

No. Instruction files, rules and prompts are text the agent reads. That makes them the easiest layer to review, but a file can still steer an agent toward risky actions, so read it before you adopt it.

Are these collections graded?

No. They are listed from their publisher's repository with a short description and carry no score, security result or verification badge. The Suede Skill Check applies to skills only.
