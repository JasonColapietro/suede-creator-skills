Install create-voltagent

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/voltagent/skills --skill create-voltagent

Claude Code, project-level copy:

git clone --depth 1 https://github.com/voltagent/skills.git /tmp/skills
mkdir -p .claude/skills
cp -R /tmp/skills/skills/create-voltagent .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo voltagent/skills \
    --path skills/create-voltagent
