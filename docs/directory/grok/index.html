Grok bots and Grok Build plugins

Directory / Grok bots and Grok Build plugins

Grok Build is xAI's open-source terminal coding agent. It reads AGENTS.md, skills, plugins, hooks and MCP servers, and installs plugins from a marketplace pinned to commits. Beside it sit the bots people build on the Grok API for Discord and other chat apps.

  • 19 listed repositories
  • 9 from official publishers
  • 3 sections

Grok Build installs with one command and keeps skills in .grok/skills in a project or ~/.grok/skills for a user. Plugins use a .grok-plugin folder with a plugin.json manifest and the same components as other agent plugins: skills, commands, agents, hooks and MCP servers. The plugin marketplace is built into the terminal and every remote plugin is pinned to a commit.

Bots on the Grok API call the xAI Responses API with function calling, search and image generation. The repositories below are community projects unless marked official; read their setup notes and token handling before you run one.

How Grok Build installs plugins and skills

Install the CLI, then add plugins from the built-in marketplace or a community catalog. Plugins that register hooks need an explicit trust flag. Skills from this directory install into .grok/skills with the skills CLI.

Commands
curl -fsSL https://x.ai/cli/install.sh | bash
grok plugin marketplace add hashgraph-online/awesome-grok-plugins
grok plugin install pbakaus/impeccable#plugin --trust
npx skills add owner/repo -a grok

Questions and answers

What is Grok Build?

Grok Build is xAI's terminal coding agent, published as open source under Apache-2.0. It reads AGENTS.md, Agent Skills, plugins, hooks and MCP servers, and installs plugins from a marketplace where every remote plugin is pinned to a commit.

Do skills from this directory work in Grok Build?

Yes. Grok Build reads skills from .grok/skills in a project and ~/.grok/skills for a user, and the skills CLI installs there with npx skills add owner/repo -a grok. Every skill page shows the command for its folder.

What is a Grok bot?

Two things share the name. Grok Bot is xAI's hosted product: a named bot with a persistent cloud computer, skills and routines, included with an X subscription. A Grok bot in a repository is a community program that calls the Grok API from a chat app such as Discord.

Does the directory grade these repositories?

No. They are listed from their publisher's repository with a short description. The Suede Skill Check scores skills only, and nothing on this page carries a score, a security result or a verification badge.
