QA agent CLI · Dashboard, MCP and four skills

agent-qa CLI by Vostride

FSL-1.1-ALv2

Describe a user journey. Get a tested run with the evidence.

agent-qa runs natural-language QA tests on web, Android and iOS apps and keeps the evidence from every run. Drive it from the CLI, review runs in the dashboard, or hand the work to your coding agent through MCP and four bundled skills.

  • Write tests in plain language

    Describe a user journey and agent-qa tests it on web, Android or iOS.

  • Keep the evidence

    Inspect each failed step beside its screenshot and the recorded run evidence in the dashboard.

  • Remember what works

    memidex keeps facts and working procedures as reviewable files in your repository, and agent-qa validates lessons from each run.

  • Work from your coding agent

    Author tests, triage failures, read run evidence and debug fixes through the agent-qa MCP tools and skills.

Before you start

Requires Node.js 24+ and a model connection. Install with npm install -D agent-qa, run npx agent-qa init, then follow the quickstart to connect a model and run the demo. Runs use the model provider you connect. Licensed under FSL-1.1-ALv2, the Functional Source License: any use other than a competing commercial product or service, with Apache-2.0 terms for each release two years after it is made available.

One skill · Claude Code and Codex plugin

Berlin Job Search

MIT

Job search coaching built for Germany.

An AI job-search coach that knows how hiring works in Germany, Berlin first and Germany-wide. Search live German job sources, check German-language and Blue Card requirements, prepare a Lebenslauf or CV, practise interviews and track applications.

  • Find roles

    Search with German and English titles across sources chosen for your field, drop off-target titles and save a ranked shortlist.

  • Check a posting

    See the German requirement with the quoted line, the salary against 2026 Blue Card thresholds, and agency and contract terms.

  • Apply and interview

    Prepare a German Lebenslauf and Anschreiben or an English CV and letter, checked against your CV, then practise mock interviews with scored feedback.

  • Track applications

    Log application news, draft follow-ups and see response rates on an offline dashboard.

Before you start

Install it as a Claude Code or Codex plugin, or add it to any agent from the repository, then say “Set up my job search.” The bundled scripts need Python 3.9+ (standard library only) and internet access, with no API keys. Your CV, profile and tracker stay on your machine in job-search/. Sources include Bundesagentur für Arbeit, Arbeitnow, Daily Berlin Jobs, company job boards and LinkedIn’s logged-out guest search, which is subject to LinkedIn’s User Agreement. The skill never applies, sends messages or creates accounts for you.

Frametell

AGPL-3.0 · Local app

Turn an idea or your material into a narrated explainer video.

Start from one sentence or hand Frametell notes, documents, PDFs, slides and images. Its director agent drafts a storyboard for you to approve, then writes and voices the narration, draws every page and checks its own work before rendering a 1080p video with subtitles and publishing notes.

  • Approve the plan first

    Sign off on the storyboard before anything is drawn, and point at any page to say what to change.

  • Narration and voice

    The agent writes the script and voices it with ElevenLabs, or with Volcengine TTS for Chinese.

  • Pages in your style

    Every page is drawn in a built-in style (warm-story, study, chalkboard, whiteboard or tech-dark) and checked with lint and screenshots.

  • A finished film

    A final check on the full video, then a 1080p MP4 with subtitles, with cost and time shown at every step.

Before you start

Download the signed and notarized app for macOS on Apple Silicon, with Chrome, Edge or Chromium installed for drawing and rendering pages. Add a model provider key under Settings (Anthropic, OpenAI, Google, OpenRouter or any OpenAI- or Anthropic-compatible endpoint) and an ElevenLabs key for the voiceover. The app runs locally with your own keys, and requests go to the model and voice providers you configure. Windows and Intel Macs run Frametell from source with Node.js 22.19+ and pnpm. AGPL-3.0 covers the app in this repository.

07

Go CLI · One root skill

lfr

MIT

Your own mail server, run by your agent.

One Go binary runs mail for your domains on one small server: mailboxes, and newsletters with their websites. Your agent operates it through the lfr CLI, on the server or over ssh.

  • Set up a mail server

    Run lfr setup with your mail hostname, add a domain and publish exactly the DNS records lfr prints; lfr doctor checks them.

  • Run mailboxes

    Create addresses, aliases and forwarding, search and answer mail, and train the spam filter as you move messages.

  • Publish newsletters

    Run lists with double opt-in and stored consent proof, Markdown issues checked before sending, one-click unsubscribe and a website for each list.

Before you start

Requires a Linux or macOS server you control and a domain whose DNS you manage. The skill installs lfr with curl -fsSL https://lfr.email/install.sh | sudo sh, which checks the release against its checksums; Homebrew and go install also work. lfr setup creates a hardened systemd service on ports 25, 80 and 443. Where a provider blocks outbound port 25, lfr hands DKIM-signed mail to an SMTP relay such as Amazon SES or SMTP2GO. Your agent asks for explicit approval before sending any message in your name.

Claude Code plugin · Memory maintenance

CoalWash

Apache-2.0

Understand what your agent carries into every session.

Measure memory and governance-file overhead, run maintenance, and inspect the changes. CoalWash pairs a structured-token guard with transaction snapshots and rollback tools.

  • Measure the overhead

    Inspect always-loaded memory and governance files before choosing a maintenance pass.

  • Review the changes

    Use snapshots and rollback tools to inspect and recover transaction changes.

  • Check structured tokens

    Detect drops in tracked tokens such as paths, numbers and commands. Review prose meaning separately.

Install the Claude Code plugin

Requires Claude Code and Node.js. Install the complete plugin so its commands, hooks and engine are available together.

Run these two commands
claude plugin marketplace add TheColliery/CoalWash
claude plugin install coalwash@coalwash

What runs after installation

The plugin registers SessionStart, Stop, PreToolUse and PostToolUse hooks. Default automatic mode can direct Quick maintenance without a new prompt; Full semantic work requires consent and uses your agent’s model. Stop hooks can hold session completion while maintenance is addressed.

Snapshot and token-check coverage

The edit guard snapshots supported Edit, Write and MultiEdit changes to memory and governance files and reports tracked-token drops. Shell writes are outside that edit guard. Token checks do not establish semantic preservation; inspect diffs and rollback results.
