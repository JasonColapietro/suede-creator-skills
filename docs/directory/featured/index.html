02

Claude Code plugin · Memory maintenance

CoalWash

Apache-2.0

Understand what your agent carries into every session.

Measure memory and governance-file overhead, run maintenance, and inspect the changes. CoalWash pairs a structured-token guard with transaction snapshots and rollback tools.

  • Measure the overhead

    Inspect always-loaded memory and governance files before choosing a maintenance pass.

  • Review the changes

    Use snapshots and rollback tools to inspect and recover transaction changes.

  • Check structured tokens

    Detect drops in tracked tokens such as paths, numbers and commands. Review prose meaning separately.

Install the Claude Code plugin

Requires Claude Code and Node.js. Install the complete plugin so its commands, hooks and engine are available together.

Run these two commands
claude plugin marketplace add TheColliery/CoalWash
claude plugin install coalwash@coalwash

What runs after installation

The plugin registers SessionStart, Stop, PreToolUse and PostToolUse hooks. Default automatic mode can direct Quick maintenance without a new prompt; Full semantic work requires consent and uses your agent’s model. Stop hooks can hold session completion while maintenance is addressed.

Snapshot and token-check coverage

The edit guard snapshots supported Edit, Write and MultiEdit changes to memory and governance files and reports tracked-token drops. Shell writes are outside that edit guard. Token checks do not establish semantic preservation; inspect diffs and rollback results.

03

Hosted MCP · Four FinOps skills

Costory

Apache-2.0

Understand your cloud bill and choose the next action.

Investigate cost changes, explore BigQuery spend, and map shared costs to teams with an agent connected to Costory. Four workflows cover discovery, evidence, allocation and review.

  • Investigate BigQuery costs↗

    Compare compute and storage billing, explore query and dataset costs, and review allocation options.

  • Explain what changed↗

    Trace contributors and timing, check usage and operational evidence, and separate supported explanations from assumptions.

  • Allocate shared costs↗

    Draft custom cost axes, preview leftovers and rule overlap, then publish approved allocation rules.

  • Start with the right workflow↗

    Choose the Costory tools and detailed skills for spend queries, investigations, budgets, dashboards, reports and alerts.

Before you start

Requires a Costory workspace with billing data connected and its hosted MCP at https://app-api.costory.io/mcp, authenticated through browser OAuth. Queries use workspace cost data. Preview changes and confirm before publishing allocations, delivering reports or applying schema changes. Each linked skill page includes setup and source details.

04

Local Mac MCP · One workflow skill

Extra Caffeine

Proprietary · All rights reserved

Keep your Mac awake while the work needs it.

Give local AI and file-processing work time to finish. The Extra Caffeine workflow guides an agent through authorized awake sessions, state checks and requested one-time schedules while preserving existing sessions.

  • One workflow: extra-caffeine-workflow

    Choose the duration and display behavior, verify awake state, and reconcile timeouts before retrying.

Before you start

Requires macOS 14+ and the separately purchased, paid Extra Caffeine 1.2+ app, kept open with AI assistants enabled by the user. Follow the publisher’s setup and license terms. The skill does not install the app or enable access. It prevents idle sleep, not closed-lid sleep, and does not wake a sleeping Mac. No security scan or runtime execution was performed: not scanned; runtime-unverified. Editorial feature only; scored catalog listing is pending the next directory refresh.
