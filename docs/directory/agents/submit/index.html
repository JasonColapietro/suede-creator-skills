Submit an AI agent

Request an AI agent listing, a fresh evidence review, or a correction or removal for a specific edition.

Choose discovery or evidence review

Request an ungraded discovery listing for a runnable agent, or a checklist review of a specific edition. Ungraded listings show official sources and a checked date, with no ratings or verification badges.

Name the edition

Send the official product URL, exact edition, deployment type and optional public repository revision. Include public setup, license or terms, permission and pricing evidence. Runnable agents are eligible; a framework alone is not an agent listing.

No credentials, private data, unverified performance scores or safety claims. Submission opens a public GitHub issue and does not run the agent or guarantee admission.

Open agent review request

For a correction or removal, link the listing and describe the exact issue. Read the evidence method.

Agent evidence reviews are separate from skill scores. Publisher claims are not runtime or security assessments.
