cypress-tap 85/100 · B

Publisher's task description: Drives a running Cypress open-mode session through `cypress tap` to run and rerun specs, wait for fresh results, inspect reporter and command logs, and query or rewind the app under test through DOM, accessibility, styles, and snapshots. Use when authoring or debugging Cypress e2e or component specs, discovering selectors, diagnosing failures, or verifying test behavior without GUI interaction. Not for one-shot headless runs. Requires Cypress 15.21+, a Chromium-family browser, and a running `cypress open` session.

  1. Select one skill. Use the folder-specific command beside its description to start with the workflow you need. Skills with publisher-specific license terms link to that publisher's setup route.
  2. Read the setup requirements. Check the source, license and any named tools or environment variables. Installing a SKILL.md folder supplies instructions to the agent; any external CLI, MCP server, account or service still needs its own setup.
  3. Check the result. Open the installed SKILL.md and confirm that its name matches your selection. In Claude Code use the project's .claude/skills/ folder; in Codex use .agents/skills/. The skills CLI also supports other Agent Skills hosts.
