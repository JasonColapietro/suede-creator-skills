Install cypress-cloud-cli

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/cypress-io/ai-toolkit/tree/main/skills/cypress-cloud-cli
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/cypress-io/ai-toolkit.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/cypress-cloud-cli .claude/skills/
rm -rf "$tmp"
Codex installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
