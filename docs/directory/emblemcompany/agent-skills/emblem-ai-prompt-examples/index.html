The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/EmblemCompany/Agent-skills/tree/main/skills/emblem-ai-prompt-examples
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/EmblemCompany/Agent-skills.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/emblem-ai-prompt-examples .claude/skills/
rm -rf "$tmp"

How the author describes it

Curated prompt and usage examples for research, portfolio review, quote requests, approval-gated drafts, NFT discovery, prediction-market analysis, and assistant workflows. Emphasis is review-first, trust-boundary-aware use of external data, and explicit confirmation before any value-moving action. Use when the user wants example prompts, phrasing guidance, or sample requests for end-user EmblemAI tasks.
