Install emblem-ai-react

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/emblemcompany/agent-skills --skill emblem-ai-react

Claude Code, project-level copy:

git clone --depth 1 https://github.com/emblemcompany/agent-skills.git /tmp/agent-skills
mkdir -p .claude/skills
cp -R /tmp/agent-skills/skills/emblem-ai-react .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
