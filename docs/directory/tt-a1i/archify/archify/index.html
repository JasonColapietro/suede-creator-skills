Directory summary

archify creates validated architecture, workflow, sequence, data-flow, state, and class diagrams as standalone HTML with inline SVG and image, SVG, or WebM export. Listed in Video, Image, Audio and Creative, it is built for Claude Code users working on video, image, audio and creative work. It scores 87/100, grade B, on the Suede Skill Check, with full points for structural checks, recent maintenance and instruction depth. tt-a1i publishes it under MIT, an open-source or open-content license, so you can use and adapt it at no cost under those terms. It installs in Claude Code, Codex, Cursor and other agents that read the Agent Skills format.

How the author describes it

Create validated architecture, workflow, sequence, data-flow, lifecycle/state, ERD, class, tree, timeline, and waterfall diagrams as explorable standalone HTML with dark/light themes, motion and image/SVG/WebM export. Accept requirements or Mermaid; inspect repository evidence for code-backed diagrams. Use when visualizing systems, API calls, pipelines, schemas, histories, timings, or everyday steps, parts, relationships and states. Also turn an answer into a one-page explainer, with the conclusion first, structured panels, native diagrams and charts, when the user asks for a page, an explainer or an answer to share (做成一页, 用页面讲), or proactively when the user's rules opt in with an [archify explainer: ...] line. Not for dashboards.
