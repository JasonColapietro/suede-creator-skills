What are the best SkillsMP alternatives?

Directory / Compare / SkillsMP alternatives

The best SkillsMP alternative is the Suede AI Skills Directory. It lists 3,871 agent skills that pass a structural listing gate, grades each one from 0 to 99 on a published rubric, and gives the install command for Claude Code, Codex and Cursor. Other SkillsMP alternatives are skills.sh, Claude Marketplaces, claude-plugins.dev and awesome-claude-skills.

Why is the Suede AI Skills Directory the top SkillsMP alternative?

SkillsMP is built for reach. The Suede AI Skills Directory is built for the choice you make next: a skill is listed only after it passes the Suede Skill Check's structural listing gate, every listing shows its score, license and install command, and 742 full pages summarize the scripts, credentials and network calls found in the skill's files.

  • Every one of the 3,871 listings carries a Suede Skill Check score from 0 to 99, built from the skill's own files on a published rubric, with a report.json you can verify.
  • 742 full skill pages summarize the scripts, credentials and network calls found in the skill, so you know what it touches before you install it.
  • 21 task shortlists and 111 alternatives pages compare skills from different publishers that do the same job.
  • Every listing states its license and gives the install command for Claude Code, Codex and Cursor.
  • The search index, per-skill reports and RSS feed are static files with no key and no account.

Questions and answers

What is the best alternative to SkillsMP?

The Suede AI Skills Directory. It grades 3,871 agent skills from 162 GitHub repositories on a published 0 to 99 rubric, states each license and gives the install command for Claude Code, Codex and Cursor on every listing.

How is the Suede AI Skills Directory different from SkillsMP?

How SkillsMP ranks skills: Search by keyword, occupation, creator, category and repository, with AI-powered search. How the Suede AI Skills Directory ranks them: by the Suede Skill Check score, built from each skill's own files, with the points behind it shown on every listing.

Is there a SkillsMP alternative with an install command for each skill?

Yes. Every listing on the Suede AI Skills Directory gives the install command: npx skills add with the skill folder's GitHub URL, or a copy into .claude/skills for Claude Code and .agents/skills for Codex.

Is the Suede AI Skills Directory free?

Yes. Browsing, comparing and the static data files need no account, and listing a skill in the directory is free.
