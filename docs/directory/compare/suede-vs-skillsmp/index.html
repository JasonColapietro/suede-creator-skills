What is SkillsMP?

SkillsMP is an independent search index of SKILL.md files collected from public GitHub repositories, not affiliated with Anthropic or OpenAI. You search it by keyword, occupation, creator, category and repository. KDnuggets reported 425,000+ skills on its home page in April 2026, and SmartScope reported 1.6M+ collected SKILL.md files in June 2026.

Why choose the Suede AI Skills Directory over SkillsMP?

SkillsMP is built for reach. The Suede AI Skills Directory is built for the choice you make next: a skill is listed only after it passes the Suede Skill Check's structural listing gate, every listing shows its score, license and install command, and 742 full pages summarize the scripts, credentials and network calls found in the skill's files.

  • Every one of the 3,871 listings carries a Suede Skill Check score from 0 to 99, built from the skill's own files on a published rubric, with a report.json you can verify.
  • 742 full skill pages summarize the scripts, credentials and network calls found in the skill, so you know what it touches before you install it.
  • 21 task shortlists and 111 alternatives pages compare skills from different publishers that do the same job.
  • Every listing states its license and gives the install command for Claude Code, Codex and Cursor.
  • The search index, per-skill reports and RSS feed are static files with no key and no account.

Questions and answers

Who runs SkillsMP?

SkillsMP is an independent project. SmartScope's review, updated in June 2026, describes it as not affiliated with Anthropic or OpenAI.

How many skills does SkillsMP index?

Published figures depend on the date: KDnuggets reported 425,000+ skills on the SkillsMP home page in April 2026, and SmartScope reported 1.6M+ collected SKILL.md files in June 2026. The Suede AI Skills Directory lists 3,871 skills that pass its listing gate, each with a score.

How does the Suede AI Skills Directory score skills?

Every listed skill gets a Suede Skill Check score from 0 to 99, read from its published files: structure, description quality, instruction depth, bundled files, maintenance and curated-list citations. The rubric is public on the methodology page.

Is the Suede AI Skills Directory free?

Yes. Browsing, comparing and the static data files need no account, and listing a skill in the directory is free.
