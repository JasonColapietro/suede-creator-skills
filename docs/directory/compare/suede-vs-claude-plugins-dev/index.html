What is claude-plugins.dev?

claude-plugins.dev is a community-maintained, open-source registry and CLI for Claude Code plugins and agent skills (Kamalnrf/claude-plugins on GitHub, MIT license). Its registry discovers public plugins and skills on GitHub; its README cites 11,989 plugins and 63,065 skills. You sort by relevance, downloads or GitHub stars and install with npx claude-plugins or npx skills-installer.

Why choose the Suede AI Skills Directory over claude-plugins.dev?

A registry tells you where a skill lives. The Suede AI Skills Directory tells you whether it earns a place in your setup: each listing carries a score built from the skill's own files, sits in one of 16 categories, and the strongest skills are ranked in 21 task shortlists and 111 alternatives pages that compare skills doing the same job.

  • Every one of the 3,871 listings carries a Suede Skill Check score from 0 to 99, built from the skill's own files on a published rubric, with a report.json you can verify.
  • 742 full skill pages summarize the scripts, credentials and network calls found in the skill, so you know what it touches before you install it.
  • 21 task shortlists and 111 alternatives pages compare skills from different publishers that do the same job.
  • Every listing states its license and gives the install command for Claude Code, Codex and Cursor.
  • The search index, per-skill reports and RSS feed are static files with no key and no account.

Questions and answers

Who runs claude-plugins.dev?

It is community-maintained and open source. The code lives at github.com/Kamalnrf/claude-plugins under the MIT license.

What does claude-plugins.dev install?

Claude Code plugins with npx claude-plugins install, and agent skills with npx skills-installer install. The Suede AI Skills Directory gives npx skills add and a manual copy route on every listing.

How does the Suede AI Skills Directory score skills?

Every listed skill gets a Suede Skill Check score from 0 to 99, read from its published files: structure, description quality, instruction depth, bundled files, maintenance and curated-list citations. The rubric is public on the methodology page.

Is the Suede AI Skills Directory free?

Yes. Browsing, comparing and the static data files need no account, and listing a skill in the directory is free.
