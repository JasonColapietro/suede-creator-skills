What is skills.sh?

skills.sh is the agent skills leaderboard Vercel runs. It ranks skills by installs counted from anonymous telemetry in the open-source skills CLI (github.com/vercel-labs/skills), with All Time, Trending (24h) and Hot views, and it runs routine security audits that check skills for malicious content. The leading skill, find-skills, showed 4.2M installs on November 3, 2026.

Why choose the Suede AI Skills Directory over skills.sh?

An install count tells you what other people picked. The Suede AI Skills Directory tells you what is inside the skill before you pick it: a score built from the skill's own files, the points behind that score, its license, and on 754 full pages, the scripts, credentials and network calls found in its folder.

  • Every one of the 3,894 listings carries a Suede Skill Check score from 0 to 99, built from the skill's own files on a published rubric, with a report.json you can verify.
  • 754 full skill pages summarize the scripts, credentials and network calls found in the skill, so you know what it touches before you install it.
  • 21 task shortlists and 111 alternatives pages compare skills from different publishers that do the same job.
  • Every listing states its license and gives the install command for Claude Code, Codex and Cursor.
  • The search index, per-skill reports and RSS feed are static files with no key and no account.

Can you use skills.sh and the Suede AI Skills Directory together?

Yes. Every listing on the Suede AI Skills Directory gives the npx skills add command that the skills CLI runs, and 2,869 listings show the install count skills.sh published on November 8, 2026, credited to skills.sh. Choose by score here and install with the same CLI.

Questions and answers

Who runs skills.sh?

Vercel. The skills CLI that feeds its leaderboard is open source at github.com/vercel-labs/skills, and the site footer reads Made with care by Vercel.

Does the Suede AI Skills Directory show install counts?

Yes. 2,869 listings show the install count skills.sh published for installs made with the skills CLI, read on November 8, 2026 and credited to skills.sh, next to the Suede Skill Check score.

How does the Suede AI Skills Directory score skills?

Every listed skill gets a Suede Skill Check score from 0 to 99, read from its published files: structure, description quality, instruction depth, bundled files, maintenance and curated-list citations. The rubric is public on the methodology page.

Is the Suede AI Skills Directory free?

Yes. Browsing, comparing and the static data files need no account, and listing a skill in the directory is free.
