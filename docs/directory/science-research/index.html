How to choose science and research skills

Most science skills wrap a specific library or database. Choose by the tool your lab already uses, and check the bundled scripts list on each page, since these skills often run Python against your data.

Database and literature skills may need an API key for the service they query. The Before you install panel shows the environment variables each skill's code reads.

Treat outputs as a starting analysis. The skills encode procedure; your data, controls and domain judgment decide whether a result holds.
