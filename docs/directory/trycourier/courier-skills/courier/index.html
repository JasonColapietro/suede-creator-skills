Install courier

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/trycourier/courier-skills --skill courier

Claude Code, project-level copy:

tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/trycourier/courier-skills.git "$tmp/courier-skills"
mkdir -p .claude/skills
cp -R "$tmp/courier-skills/skills/courier" .claude/skills/
rm -rf "$tmp"

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo trycourier/courier-skills \
