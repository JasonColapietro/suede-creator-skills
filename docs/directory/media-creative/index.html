How to choose video, image, audio and creative skills

Separate the skills that generate media through a hosted model from the ones that edit files locally. Hosted ones usually read an API key, shown under Before you install, and usage is billed by that provider.

Local editing skills usually call tools such as FFmpeg or a rendering library from bundled scripts. Check the scripts list and make sure those tools are installed.

For brand work, pick skills that accept your own assets and specs as input, so results stay consistent across a campaign.
