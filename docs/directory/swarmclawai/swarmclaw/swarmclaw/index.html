Install swarmclaw

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/swarmclawai/swarmclaw --skill swarmclaw

Claude Code, project-level copy:

tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/swarmclawai/swarmclaw.git "$tmp/swarmclaw"
mkdir -p .claude/skills
cp -R "$tmp/swarmclaw/swarmclaw" .claude/skills/
rm -rf "$tmp"

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo swarmclawai/swarmclaw \
