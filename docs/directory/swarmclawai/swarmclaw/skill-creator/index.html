Install skill-creator

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/swarmclawai/swarmclaw/tree/main/skills/skill-creator
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/swarmclawai/swarmclaw.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/skill-creator .claude/skills/
rm -rf "$tmp"
Codex installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo swarmclawai/swarmclaw \
    --path skills/skill-creator

How the author describes it

Create, edit, improve, or audit skills for SwarmClaw agents. Use when creating a new skill from scratch or when asked to improve, review, audit, tidy up, or clean up an existing skill or SKILL.md file. Also use when editing or restructuring a skill directory. Triggers on phrases like "create a skill", "author a skill", "tidy up a skill", "improve this skill", "review the skill", "clean up the skill", "audit the skill".
