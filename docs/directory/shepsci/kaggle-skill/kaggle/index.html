Install kaggle

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/shepsci/kaggle-skill/tree/main/skills/kaggle
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/shepsci/kaggle-skill.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/kaggle .claude/skills/
rm -rf "$tmp"
Codex, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/shepsci/kaggle-skill.git "$tmp/repo"
mkdir -p .agents/skills
cp -R "$tmp/repo/"skills/kaggle .agents/skills/
rm -rf "$tmp"

For a user-level install, copy the folder to ~/.claude/skills/ (Claude Code) or ~/.agents/skills/ (Codex). Inside Codex, $skill-installer can also fetch a skill from GitHub. New to skills? Read How to install agent skills in Claude Code, Codex and Cursor.

kaggle handles Kaggle tasks when explicitly requested, covering competitions, datasets, models, notebooks, forums, benchmarks, hackathons, badges, and account setup. Listed in Data, Analytics and Databases, it is built for Claude Code users working on data, analytics and databases. It scores 90/100, grade A, on the Suede Skill Check, with full points for structural checks, recent maintenance and instruction depth. shepsci publishes it under MIT, an open-source or open-content license, so you can use and adapt it at no cost under those terms. How the author describes it

Unified Kaggle skill. Use when the user explicitly mentions Kaggle, kaggle.com, a Kaggle URL, Kaggle competitions, Kaggle datasets/models/notebooks, Kaggle forums/discussions/writeups, Kaggle benchmarks, hackathons hosted on Kaggle, Kaggle badges, or Kaggle account setup. Do not use for generic ML, GPU/TPU, notebook, dataset, benchmark, or data-science tasks unless the user clearly ties them to Kaggle.
