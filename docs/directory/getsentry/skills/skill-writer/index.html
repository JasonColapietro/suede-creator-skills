Install skill-writer

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/getsentry/skills --skill skill-writer

Claude Code, project-level copy:

git clone --depth 1 https://github.com/getsentry/skills.git /tmp/skills
mkdir -p .claude/skills
cp -R /tmp/skills/skills/skill-writer .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo getsentry/skills \
    --path skills/skill-writer

getsentry/skills is third-party code. Suede lists it and links to the source; read SKILL.md and any bundled scripts before you install it.
