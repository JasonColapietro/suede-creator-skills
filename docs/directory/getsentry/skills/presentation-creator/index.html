Install presentation-creator

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

git clone --depth 1 https://github.com/getsentry/skills.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/presentation-creator .claude/skills/
rm -rf "$tmp"
Codex, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/getsentry/skills.git "$tmp/repo"
mkdir -p .agents/skills
cp -R "$tmp/repo/"skills/presentation-creator .agents/skills/
rm -rf "$tmp"

For a user-level install, copy the folder to ~/.claude/skills/ (Claude Code) or ~/.agents/skills/ (Codex). Inside Codex, $skill-installer can also fetch a skill from GitHub. New to skills? Read How to install agent skills in Claude Code, Codex and Cursor.
