Install skill-scanner

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/getsentry/skills --skill skill-scanner

Claude Code, project-level copy:

git clone --depth 1 https://github.com/getsentry/skills.git /tmp/skills
mkdir -p .claude/skills
cp -R /tmp/skills/skills/skill-scanner .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo getsentry/skills \
    --path skills/skill-scanner
