Install skill-scanner

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/getsentry/skills/tree/main/skills/skill-scanner
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/getsentry/skills.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/skill-scanner .claude/skills/
rm -rf "$tmp"
Codex installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo getsentry/skills \
    --path skills/skill-scanner
