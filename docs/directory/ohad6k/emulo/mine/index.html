Install mine

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/ohad6k/emulo/tree/main/skills/mine
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 https://github.com/ohad6k/emulo.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/skills/mine" .claude/skills/
rm -rf "$tmp"
Codex installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo ohad6k/emulo \
    --path skills/mine
