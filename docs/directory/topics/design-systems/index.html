How to choose design system skills

Extraction skills read a website, Figma file or Stitch project and write the system down. Authoring skills define tokens and components from scratch. Governance skills handle versioning and adoption.

Some extraction skills need Firecrawl or Figma access; check the Before you install panel.

Pick one token format and keep every skill writing to it, so code, slides and video share the same values.
