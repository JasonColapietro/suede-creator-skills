How to choose summarizer skills

Pick by source. URL and article skills fetch and clean pages, video skills pull transcripts or keyframes, and interview and meeting skills work from a transcript you paste in.

Some summarizers call an external tool or API, such as the summarize CLI or a transcript service. The Before you install panel lists any key or binary they need.

Ask for the summary format you will use. Skills that output decisions, action items or quotes with timestamps are easier to verify than a free-form paragraph.
