How to choose sales skills

Decide whether you need research, data or writing. Playbook skills (cold email frameworks, sales enablement, Predictable Revenue, forward deployed selling) are Markdown and need no keys; enrichment and email finder skills call a paid data provider and list its API key under Before you install.

Large collections such as the Gooseworks set split prospecting into many small skills: signal detection, enrichment, qualification, sequencing. Install the orchestrator or lead discovery skill with the pieces it calls, so hand-offs between steps work without extra prompting.

Check deliverability and consent rules before sending. Sequencing skills that set up Smartlead or other senders act on a real mailbox, so run them against a test domain and keep a human approval step before the first send.
