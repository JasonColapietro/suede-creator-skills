How to choose coding assistant skills

Separate method skills from delegation skills. Refactoring and implementation workflows run inside your own agent as Markdown instructions; delegation skills hand work to another coding agent and need that agent's CLI or account set up first.

Refactoring skills range from single named moves (extract method, remove parameter) to multi-file plans. Pick the narrow ones for routine cleanup and the planning ones before a change that touches many files.

Workflow skills like tiny stepping or implement-from-spec change how the agent approaches every task. Install one method and keep it, since overlapping methods give the agent conflicting instructions.
