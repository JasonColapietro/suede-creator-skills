How to choose personal assistant skills

Most assistant skills act on your accounts. Google Workspace skills use the gws CLI with OAuth, WorkIQ uses its CLI or MCP server for Microsoft 365, and SMS sends through a Textbelt key, all listed under Before you install.

Briefing skills such as daily prep and roundup read several sources and produce one summary. Configure their data sources once and run them on a schedule.

Keep send and book actions behind your approval. Skills that book tables or send texts act in the real world, so review the draft before the agent completes it.
