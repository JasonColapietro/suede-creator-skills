How to choose product description and listing skills

Choose by storefront. amazon-listing-checker reviews pasted Amazon copy with a local Python script; aso and suede-aso cover App Store and Google Play fields; seo-ecommerce and ecommerce-seo audit product and category pages on your own store.

Marketplace analysis that pulls live Shopping or Amazon data uses a data provider such as DataForSEO, so check the key the skill lists. Copy review skills run on the text you paste.

For new product copy from scratch, pair a listing skill with a copywriting skill. The listing skill enforces structure and limits; the copywriting skill supplies the angle and proof.
