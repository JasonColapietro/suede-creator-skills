How to choose deployment skills

Pick the skill for the host you already pay for. OpenAI publishes short deploy skills for Vercel, Netlify, Render and Cloudflare; Vercel, Firebase, Expo and Microsoft publish their own.

Deploy skills need a host token or CLI login, listed under Before you install. Use preview or staging deployments first, and keep production promotion a separate step.

Mobile teams should look at the Expo EAS skills, which cover over-the-air updates, store submission and hosting from one CLI.
