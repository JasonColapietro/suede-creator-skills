How to choose Docker and container skills

For a new service, start with a Dockerfile skill (multi-stage builds, framework-specific containerization) and add a registry skill once you push images to ECR, ACR or a HashiCorp-managed registry.

Container skills run docker or podman commands locally. Check that the runtime is installed and that the agent may run it; the Before you install panel lists which skills ship scripts.

For GPU and research stacks, the NVIDIA container skills (Holoscan, DOCA, TAO) pin specific base images and driver versions, so match them to the hardware you run.
