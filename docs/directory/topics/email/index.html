How to choose email skills

Decide which layer you need. Copy skills (emails, cold-email, email-drafter) produce sequences and drafts; developer skills (react-email, resend, sending-emails) build templates and send through an API; Gmail and Google Workspace recipes act on a real inbox.

Check credentials up front. Resend, Mailtrap, SES and Smartlead skills need that provider's API key, and the Gmail and gws recipes need an authorized Google account. Drafting and sequence-planning skills run on the brief you give them.

For outbound, pick a skill that treats deliverability and consent as part of the job: bounded follow-up counts, unsubscribe handling, and current Gmail and Yahoo sender rules. Review every send step yourself before a campaign goes live.
