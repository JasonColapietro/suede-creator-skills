How to choose Kubernetes skills

Most listings are vendor-published: Google ships a large GKE set (cluster creation, autoscaling, workload identity, TPU and GPU troubleshooting) and Microsoft ships AKS skills. Choose the set for the managed service you run.

Cluster skills act on live infrastructure through kubectl and the cloud CLI. Give the agent a context scoped to a dev namespace or cluster, and read the tool permissions on each page first.

For day-to-day development against a shared cluster, the mirrord skills set up local processes that borrow cluster traffic and config; they need the mirrord CLI and, for some features, the mirrord operator.
