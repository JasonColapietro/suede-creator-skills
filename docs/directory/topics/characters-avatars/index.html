How to choose character and avatar skills

For a recurring character across a story or ad series, choose a skill that keeps a character bible or reference set, since consistency is the hard part.

Sticker and pet skills produce small animated files with fixed size rules, so check their output format against where you will post them.

Most of these call hosted image models through fal.ai or MiniMax, so plan for an API key and per-image cost.
