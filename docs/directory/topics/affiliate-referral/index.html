How to choose affiliate and referral skills

Use referrals and suede-referrals for program mechanics: who earns what, when payouts happen, how disclosure works, and which fraud patterns to block. Use co-marketing skills when the partner is another company rather than an individual.

Check that the program design names its measurement. A referral program needs a tracked link or code and a reporting view on day one, so pair it with a marketing analytics skill.

These skills are procedure and need no credentials. Your referral or affiliate platform and payment provider handle the live program.
