How to choose YouTube skills

Most listings use a third-party transcript API rather than Google's YouTube API, so they skip OAuth. Some are metered, so check pricing.

The ZeroPointRepo set splits by task (search, channel, playlist and transcript); install only the ones you need.

For learning, the learn-this and ship-learn-next skills turn a video into notes and an action plan.
