How to choose AI agent builder skills

Pick the skill for the framework you already run. LangChain, Google Genkit, VoltAgent, Cloudflare and AWS each publish their own builder skills, and several ship a quickstart skill per language, so install the Python or TypeScript one that matches your project.

Platform skills such as AWS AgentCore, Gemini Enterprise Agent Platform and Microsoft Foundry act on a cloud account. Check the environment variables under Before you install and point them at a sandbox project before you let the agent deploy.

Architecture skills (agent-architecture, agent-advisor, the Google Cloud solution designers) produce a design before any code. Run one of those first when the framework is still undecided, then add the framework skill once you have chosen.
