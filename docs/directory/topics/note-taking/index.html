How to choose note taking skills

Pick the home for your notes first. Notion skills need the Notion MCP server or API token, NotebookLM skills use a browser profile login, and Markdown wiki and vault skills write plain files to a folder you control.

Notion has two parallel collections, from Notion and from OpenAI, covering the same jobs. Install one set so your agent has a single way to capture and search pages.

Capture skills work best on a routine. Run session logs and knowledge capture at the end of each working session, so notes stay complete without a separate cleanup pass.
