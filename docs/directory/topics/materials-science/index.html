How to choose materials science skills

The HeshamFS materials-simulation collection is designed to work together: plan with the solver and stability skills, run with slurm-job-script-generator, and check with convergence-study and simulation-validator.

Many skills bundle Python scripts that compute stability limits or convergence orders. The scripts list on each page shows what runs and which packages it needs.

Use simulation-failure-triage and hpc-runtime-doctor when a job fails. They classify the failure from logs before you change parameters.
