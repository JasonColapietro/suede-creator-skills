How to choose vector database skills

Qdrant publishes the largest set, one skill per task (hybrid search, sizing, scaling, latency, quality diagnosis); other stores have one skill each. Choose by the database you run.

Hosted vector stores need an API key and endpoint, listed under Before you install. Local options such as FAISS and Chroma run without an account and suit prototypes.

Search quality depends on the embedding model as much as the store. Keep a small labeled query set so the agent can measure recall before and after a change.
