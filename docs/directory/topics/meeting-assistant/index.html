How to choose meeting skills

Split prep from follow-up. Prep skills read your calendar and research attendees, sometimes with paid enrichment sources; follow-up skills work from a transcript or notes you supply and need no account access.

The pm-skills meeting set (agenda, brief, recap, synthesize) shares one format, so recaps feed the synthesis skill cleanly. Install the four together if you run many recurring meetings.

Notion meeting intelligence skills pull context from your workspace into pre-reads. They need the Notion connection set up, which the Before you install panel notes.
