How to choose iOS and Swift skills

Most build and simulator skills need macOS with Xcode installed. Check the scripts list for the commands each one runs.

Design skills such as HIG and iOS design review are Markdown guidance and pair well with an implementation skill like swift-expert or ios-application-dev.

For cross-platform apps, the Expo skills that touch Swift (native modules, App Clips, brownfield) also appear here.
