How to choose Android and Kotlin skills

Building and testing need the Android SDK and Gradle locally. Check the scripts list on each page for what runs.

Google's Mobile Ads skills follow the current GMA SDK, including the next-gen migration, and expect an AdMob account for live ads.

Release skills prepare Play delivery; uploads need your Play Console service account, which the skill reads from your environment.
