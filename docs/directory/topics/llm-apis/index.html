How to choose LLM API skills

Use the provider's own skill for the API you call. Google, OpenAI, AWS, Firebase and Venice publish skills that track their current endpoints, which matters when model names and parameters change often.

Every skill here reads an API key or cloud credential, listed under Before you install. Keep keys in environment variables and give each app its own key.

If you route across several providers, a gateway skill (azure-aigateway, neon-ai-gateway) centralizes keys, rate limits and caching in one place instead of in each app.
