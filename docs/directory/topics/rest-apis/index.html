How to choose REST API skills

Start from a spec. Design skills produce OpenAPI documents that the SDK, Postman and test generators then take as input.

Postman and Newman skills output import-ready collections and CI commands; running them against a live API needs its credentials.

Framework skills for Django, Fastify and ASP.NET minimal APIs also appear here when they build REST endpoints directly.
