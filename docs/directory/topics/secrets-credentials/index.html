How to choose secrets management skills

Use a scanning skill to find secrets already in a repository, then a storage skill (Secrets Manager, Varlock, workload identity) so new ones never land in code.

These skills touch credentials directly. Read SKILL.md before installing, and confirm that the agent never prints secret values into the transcript.

Rotation skills change live keys. Run them with the owning service's team, and check every consumer picks up the new value before the old one is revoked.
