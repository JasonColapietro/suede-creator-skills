How to choose tutoring and course skills

Match the skill to the learner. Code tutorial skills assume a programming student; learning-plan skills work from any article or transcript you supply.

Ask for output you can check, such as a commented file, a step list or a small exercise, so the learner practices instead of only reading.

Most of these skills are Markdown with no scripts or keys. The model-implementation skills are the exception and expect a Python environment with GPU access for full runs.
