How to choose health and medical skills

Separate research tooling from clinical use. Most of these skills prepare, check or format work for licensed professionals and research teams, and their SKILL.md files state that scope.

Imaging and pipeline skills run Python against local files. Check the scripts list, and keep protected health information on systems approved for it; several DICOM skills flag PHI tags for you.

NVIDIA's healthcare skills call hosted endpoints and read an NVIDIA API key, listed under Before you install. Use de-identified data when you try them.
