How to choose Google Cloud skills

Pick by product. The GKE and BigQuery sets are the largest, followed by observability (logging queries, PromQL, alerting) and the Agent Platform skills for model tuning and deployment.

These skills drive gcloud, bq and firebase commands under your login. Check the project and IAM role the agent uses, and keep it on a non-production project until you trust the output.
