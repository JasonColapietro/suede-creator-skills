How to choose data analysis skills

Choose by data size and where it lives. pandas-pro and Polars suit a single machine, Dask, Spark and cuDF scale out or onto GPUs, and the BigQuery and Honeydew skills query data in place.

Skills that connect to live data read connection strings or API keys, listed under Before you install. The sanjay3290 SQL skills run read-only queries, which is the right default for analysis.

Ask for the method with the answer. data-scientist and exploratory-data-analysis report assumptions and checks alongside results, so a reviewer can follow the numbers.
