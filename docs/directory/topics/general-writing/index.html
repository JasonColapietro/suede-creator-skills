How to choose writing skills

Pick a skill whose default format matches your work. internal-comms covers status updates and newsletters in a company format; doc-coauthoring runs a structured drafting workflow for proposals and specs; eli5 picks the clearest form for an explanation.

Style contracts such as prose-style and writing-guidelines are most useful installed once and applied everywhere, so every draft your agent writes follows the same rules.

These skills are plain Markdown and need no credentials. Read the standard in the SKILL.md before you install it; it is the whole product.
