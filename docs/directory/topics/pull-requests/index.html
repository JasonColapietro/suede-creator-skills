How to choose pull request skills

For authoring, choose a PR writer or creator skill whose description template matches your repository's; for follow-through, add a babysitter or iterate skill that watches checks and comments.

PR skills use the gh CLI or a GitHub token. Give the agent permission to open and update PRs, and keep merging a human decision unless your team says otherwise.

Split-PR skills break large changes into a stack. They work best when the agent knows the review order your team prefers.
