How to choose React and Next.js skills

Check the React version each skill targets. The React 18 and 19 migration skills are written as before-and-after patterns for that upgrade, while best-practice skills assume a current release.

For Next.js, prefer skills written for the App Router if that is what you run; several cover server components and server actions directly.

Vercel's React skills are guidelines in Markdown and quick to adopt. Skills that deploy, such as Next.js on Cloudflare, need that platform's CLI and credentials.
