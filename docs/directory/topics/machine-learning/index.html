How to choose machine learning skills

Pick by model family. scikit-learn suits tabular data, Lightning and Transformers suit deep learning, torch-geometric suits graphs, and the RL skills suit agents in simulated environments.

Track experiments from the first run. huggingface-trackio, experiment-tracking-swanlab and ml-pipeline record parameters and metrics so results stay comparable.

Most skills run Python and some expect GPUs; the scripts list and SKILL.md say which. Explainability skills such as SHAP are worth adding before a model's predictions reach users.
