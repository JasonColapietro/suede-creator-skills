How to choose agent safety skills

Separate runtime guardrails from review skills. NeMo Guardrails, LlamaGuard and Prompt Guard filter inputs and outputs in a running app; agent-governance, ax-audit and mcp-security-audit review a design or configuration once.

For coding agents, the lightest protection is a hook. git-guardrails-claude-code and careful block dangerous commands before they run, with no service behind them.

Identity skills (entra-agent-id, entra-agent-user) change tenant settings. Run them with an admin who owns that tenant and keep the resulting permissions as narrow as the task needs.
