How to choose grammar and proofreading skills

grammar-check suits short business text where you want minimal changes; line-editing suits fiction and long-form prose; writing-guidelines and voice-style enforce a written style guide you already have.

Ask for changes with reasons. Every skill here can return a list of edits instead of a rewritten file, which keeps your voice intact and makes review quick.

These skills are plain Markdown and need no credentials or network access.
