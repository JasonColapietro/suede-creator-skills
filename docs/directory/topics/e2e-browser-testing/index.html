How to choose end-to-end testing skills

Playwright and Cypress have the most listings, including official Cypress skills and several Playwright collections; pick the one that matches the runner already in your repo.

Browser skills launch a real browser or simulator. Check that Playwright browsers, a Cypress install or the iOS simulator are available where the agent runs, and give it a test account rather than a real user.

Flaky-test skills (flake fixers, result triage) read previous runs. Feed them CI artifacts or traces so fixes rest on evidence.
