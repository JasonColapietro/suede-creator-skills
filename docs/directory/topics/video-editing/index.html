How to choose video editing skills

ffmpeg-based skills run locally and only need ffmpeg installed. CapCut skills edit CapCut and JianYing project files.

Evidence-based editors such as Orkas stage-edit read the transcript and frames before cutting, which suits interviews and talks.

For short fixes, the hook replacement and UGC fix-loop skills change one window and keep the rest.
