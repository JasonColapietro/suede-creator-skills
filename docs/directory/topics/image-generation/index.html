How to choose image generation skills

Pick by provider first. Most of these skills call one hosted API (OpenAI, Google Gemini, OpenRouter, fal.ai, Bria, Replicate or Venice) and expect that provider's key in an environment variable, so the right skill is usually the one for the account you already pay for.

If you switch models often, prefer a skill that routes through OpenRouter or fal.ai, since one key reaches several image models. If you need precise layout, lighting or camera control, look at the structured prompt skills such as Bria VGL and the Replicate prompting guide.

Check what the skill does with output. Some save files locally, some return URLs, and some build an HTML gallery. The Before you install panel lists bundled scripts and the variables their code reads.
