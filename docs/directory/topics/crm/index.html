How to choose CRM skills

Pick by the CRM you run. The GoHighLevel skill works through the NotFair MCP server, the Salesforce skills cover Apex, Lightning Web Components and Flow for developers, and the Google Workspace recipe writes deal updates to a sheet with no CRM at all.

RevOps skills define lifecycle stages, scoring, routing and handoff rules. Use them to design the process first, then apply it with the CRM-specific skill for your platform.

Any skill that writes to a CRM changes shared records. Start with a sandbox org or a test sub-account, and check the tool permissions listed on each page before you grant write access.
