How to choose Expo and React Native skills

Start with expo-overview from the Official Expo collection. It routes each task to the skill that owns it.

EAS skills build, submit and update apps through Expo's cloud and need an Expo account and the EAS CLI; store submission also needs your Apple and Google developer credentials.

Community React Native skills and Vercel's React Native guidelines are Markdown only, so they suit any React Native project, Expo or bare.
