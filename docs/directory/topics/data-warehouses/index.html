How to choose data warehouse skills

Use the vendor skill for your warehouse. Google's BigQuery set covers basics, optimization, troubleshooting and BigQuery ML; AWS covers Redshift migration and data lake queries.

Warehouse queries cost money per byte or per second. Ask the agent to estimate scan size or use a dry run before it runs large queries, and give it a role limited to the datasets it needs.

Semantic layer skills (Honeydew, Snowflake semantic views) define metrics once so every query and dashboard agrees; add them when several teams report on the same numbers.
