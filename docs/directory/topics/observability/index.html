How to choose observability skills

Choose by where your telemetry lives. Google's logging and monitoring skills write queries and alert policies, AWS covers CloudWatch, Microsoft covers Application Insights, and the Sentry skill reads issues from your Sentry org.

Query and alerting skills need read access to the monitoring backend, and some create notification channels. Give the agent a role that can read telemetry and propose alerts before it can change them.

For a new product, start with an instrumentation baseline (structured logs, error capture, health endpoints) and add dashboards and SLO alerts once traffic is real.
