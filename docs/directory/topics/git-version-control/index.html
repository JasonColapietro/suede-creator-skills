How to choose Git skills

Commit skills set message format (conventional commits, gitmoji, storytelling). Pick the format your repository already uses and install only that one.

Worktree and branch skills let an agent work on several changes at once without stepping on your checkout; they need Git 2.5 or later.

GitHub skills run the gh CLI with your token. Keep destructive actions such as force pushes and branch deletion behind your own confirmation.
