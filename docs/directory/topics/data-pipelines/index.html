How to choose data engineering skills

Start with the orchestrator you run. Google covers managed Airflow authoring, troubleshooting and migrations; AWS covers MWAA, Kinesis, MSK and data lake ingestion.

Pipeline skills touch production data and cloud resources. Give the agent a dev environment and a sample dataset, and review DAG and job changes before they deploy.

Dataframe skills (Polars, Dask, cuDF, Ray Data) help with the transform step itself; pick by data size and whether you have a GPU.
