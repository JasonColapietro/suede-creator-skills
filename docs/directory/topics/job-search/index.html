How to choose job search skills

Start with a current master resume. Matching, gap analysis and application skills all read it as their source.

Search and posting skills call live data providers such as Firecrawl or LinkedIn enrichment services and read their API keys, listed under Before you install.

Review every application an agent fills before it is submitted; employers read exactly what is sent.
