How to choose CLI skills

Pick the builder skill for your language. Go, Dart, TypeScript and System.CommandLine skills each follow that ecosystem's packaging and argument parsing conventions.

cli-creator turns API docs or an OpenAPI spec into a composable CLI, a quick route when you need agent-friendly access to a service.

Terminal workflow skills such as tmux control and terminal titles change how the agent runs commands. They are small Markdown skills and easy to try.
