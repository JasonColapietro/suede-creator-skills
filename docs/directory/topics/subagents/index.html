How to choose subagent skills

Choose one orchestration method and stay with it. obra/superpowers and NeoLabHQ's context-engineering-kit each ship a complete set (parallel dispatch, step-by-step execution, judges), and mixing their rules in one session produces conflicting instructions.

Delegation skills hand tasks to a separate product. Jules, Grok Build and Manus each need their own account and CLI or API key, listed under Before you install, and they run outside your local session.

Use the design guides (multi-agent-patterns, agent-orchestration-advisor) before you write a workflow script. They cover context isolation, handoffs and when one agent is enough, which saves tokens on tasks that do not split cleanly.
