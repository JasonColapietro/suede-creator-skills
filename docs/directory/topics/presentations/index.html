How to choose presentation skills

Choose by the file your audience opens. PPTX skills produce editable PowerPoint files, Google Slides skills write to a Drive account, and HTML deck skills produce a web page you present from a browser.

Several collections split deck work into planning, design system and single-slide steps. MiniMax ships an orchestration skill plus editing and slide-making skills; install them together so each step hands off cleanly.

Check the license on each page. The Anthropic document skills use proprietary terms that restrict copying, and the directory shows that in place of install commands.
