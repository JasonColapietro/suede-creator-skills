How to choose marketing analytics skills

Pick by question. Tracking skills (analytics, suede-analytics) build the event plan; attribution skills explain why dashboards disagree; ab-testing and suede-ab-testing handle sample size, duration and significance; Google Analytics API skills manage properties and pull reports.

API skills need a Google Cloud project and Analytics access, and the Data Manager API skills need a Google Cloud project with that API enabled. Planning and readout skills work from exports you paste in.

Favor skills that verify instrumentation by reading back what actually fires rather than trusting the tag configuration. A tracking plan is only useful once every key event shows up in the report it feeds.
