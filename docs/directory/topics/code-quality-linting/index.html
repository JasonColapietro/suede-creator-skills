How to choose code quality skills

Start with the linter your project already runs. Skills tied to a tool (ESLint, Ruff, Roslyn, Dart analysis) fix findings in the way that tool expects.

Style and clean-code skills set rules the agent follows while writing. Pick one standard per language so the rules do not conflict.

Pre-commit and formatting skills change project config. Review the hook list they add and run it once across the repo before the team adopts it.
