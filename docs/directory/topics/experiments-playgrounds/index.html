How to choose experiment and playground skills

Use the playground skill when you want an interactive single-file page to explore an idea; it needs no server.

Thought experiment and what-if skills are reasoning procedures, so give them a concrete decision or hypothesis to test.

All three are light installs with no keys, which makes them easy to try on a real question today.
