How to choose inference skills

Start from the hardware. huggingface-local-models and llama-cpp cover CPUs and Apple Silicon, the Jetson skills cover NVIDIA edge devices, and vLLM, SGLang and TensorRT-LLM cover data-center GPUs.

Quantization skills change model accuracy. Run an eval before and after, and keep the unquantized weights so you can compare outputs on your own prompts.

Hosted options (Replicate, Agent Platform endpoints, GKE) bill by usage and read cloud credentials, shown under Before you install. Set a budget alert before you leave an endpoint running.
