How to choose SQL and database skills

Start with the engine you run. Vendor collections from Redis, Qdrant, Neon, Supabase and AWS encode dialect details and limits that general SQL skills miss.

Check whether a skill connects to a live database. Query runners for Postgres, MySQL and SQL Server read connection settings from environment variables; give them a read-only role first.

For migrations, such as Oracle to PostgreSQL, install the whole set from one collection. Those skills hand plans, code changes and test projects to each other in sequence.
