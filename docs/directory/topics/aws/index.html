How to choose AWS skills

Look for the Official tag. AWS publishes one skill per service or task (creating a production VPC, securing S3 buckets, setting up CloudTrail), and those track the current CLI and console.

Every skill that acts on resources uses your AWS credentials. Sign in with a least-privilege role, and test against a sandbox account before pointing the agent at production.

For a new project, the startup and architecture skills (architect-for-startups, well-architected review) set the plan; the per-service skills then carry it out.
