How to choose app builder skills

Decide whether you want a method or a platform. Guided skills such as create-app and design-code-architecture work with any stack; AWS Amplify, AWS Blocks, Azure and Google Cloud skills target that provider and need its CLI and account.

Scaffold skills encode a house toolchain. Read the generated stack in SKILL.md before you adopt it, since a scaffold is easiest to change on day one.

Mobile builders, such as the Android and site-to-iOS factories, need the platform SDKs installed locally. The Before you install panel lists the scripts each one runs.
