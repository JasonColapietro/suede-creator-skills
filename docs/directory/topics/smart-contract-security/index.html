How to choose smart contract and blockchain skills

For contract security, start with Trail of Bits' building-secure-contracts set: audit prep, code maturity, guidelines and the scanner for your chain.

Wallet, swap and portfolio skills move real assets through a provider API. Read SKILL.md for the provider and key each one needs, and test with small amounts or a testnet.

Scanner output is a starting list for a human auditor; ask the agent to show the code path for each finding.
