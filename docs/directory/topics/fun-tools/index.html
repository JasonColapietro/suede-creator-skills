How to choose fun skills

Sticker and singing skills call hosted image, video or music models and read an API key, listed under Before you install.

The pet and sprite skills bundle scripts that validate and package animations; check the scripts list before you run them.

These install fast and make good first skills when you are learning how skill routing works.
