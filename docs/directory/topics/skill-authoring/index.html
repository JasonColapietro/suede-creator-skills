How to choose skill authoring skills

Use a creator skill for the first draft and an evaluator for the second pass. skill-creator, skill-writer and agent-skills-creator structure the folder and description; test-skill, skill-evaluator and skill-improver check that it actually changes behavior.

Description wording decides when a skill loads. skill-optimizer and the routing checks in agent-skills-creator focus on that line, which is where most weak skills fail.

Finder skills (find-skills, find-skill, nvidia-skill-finder) install third-party code. Read the SKILL.md and scripts of anything they suggest before you approve the install.
