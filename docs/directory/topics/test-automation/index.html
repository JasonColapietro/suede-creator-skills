How to choose test automation skills

Pick the skill for your test runner. LambdaTest publishes one skill per framework, GitHub's Copilot collection covers .NET, Java and JavaScript runners, and Trail of Bits covers fuzzing and mutation testing.

Method skills (TDD, test audits, fixing failing tests) work with any runner and change how the agent approaches every task; choose one and keep it.

Some skills target a vendor cloud (LambdaTest HyperExecute, Cypress Cloud) and read an account key, shown under Before you install; the framework skills themselves run locally.
