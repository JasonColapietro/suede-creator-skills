How to choose technical writing and documentation skills

Writers and auditors are separate. diataxis-writer, documentation, code-documenter and api-documentation write docs; docs-auditor, api-docs-quality-report and sdk-docs-auditor crawl a published site and score it.

Language skills (go-documentation, dart-write-documentation, csharp-docs, java-docs) follow one ecosystem's conventions, so install the one that matches your codebase. Release note skills work from tickets, PRDs or git history.

Most of these skills are plain Markdown with no credentials. Site auditors fetch pages over the network and some produce an HTML report you can share with the docs owner.
