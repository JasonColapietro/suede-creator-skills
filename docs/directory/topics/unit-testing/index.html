How to choose unit testing skills

Choose by language and runner; a skill written for your runner produces assertions, fixtures and mocks that pass review without rewrites.

TDD skills set a red, green, refactor loop for the agent. They pay off most when you ask for one behavior at a time and let the failing test lead.

Coverage, mutation and property-based skills measure how strong existing tests are. Use them after the suite is green to find what it misses.
