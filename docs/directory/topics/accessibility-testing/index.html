How to choose accessibility testing skills

Use an audit skill to find issues in an existing interface and a test-plan skill to keep them from returning; the two work well together.

Automated checks catch contrast, labels and roles. Ask the agent for a keyboard-only and screen reader pass as well, since many barriers only show up there.

Color and contrast critique skills are quick to run on a design or screenshot before any code exists.
