How to choose copywriting skills

Use a writing skill to draft and an editing skill to tighten. copywriting and suede-copy produce page copy; copy-editing, generic-language-killer and ogilvy-copywriting review and sharpen what you already have.

Give each skill real inputs: product facts, customer language, proof you can cite, and the offer. Skills that ask for these before drafting produce copy you can publish with fewer rewrites.

For ads, choose a skill that checks platform character limits (google-ads-copy, ad-creative). For product interfaces, ux-writing covers error messages, empty states and button labels.
