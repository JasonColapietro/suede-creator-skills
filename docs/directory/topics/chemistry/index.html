How to choose chemistry skills

Start with RDKit or Datamol for parsing and descriptors, then add a task skill (docking, property prediction, generation) on top. The task skills assume clean SMILES or SDF input.

Hosted models (NVIDIA NIM, Rowan, Tamarind) send structures to an external API and read its key, shown under Before you install. Keep proprietary compounds off hosted services your agreements do not cover.

Treat predictions as candidates for experiment. medchem filters and docking scores rank molecules; your assays decide.
