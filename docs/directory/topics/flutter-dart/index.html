How to choose Flutter and Dart skills

Install from the Official Flutter collection first. Its skills are narrow, one task each, so you can add only the ones your app needs.

Some skills use the Dart and Flutter MCP tools to fetch runtime errors or drive the app. Read SKILL.md for the MCP server setup.

Community skills, such as flutter-dev and flutter-expert, cover state management choices like Riverpod and Bloc in one place.
