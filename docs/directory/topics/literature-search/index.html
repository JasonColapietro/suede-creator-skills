They help an agent build a reading list with real, checkable references.

How to choose literature search skills

Pick by field. Biomedical work suits paperclip and firecrawl-research-index; ML papers suit huggingface-papers and arXiv; paper-lookup and citation-management search across many scholarly APIs at once.

Several skills call a paid or keyed service (Firecrawl, BGPT, Paperzilla, Zotero). The Before you install panel lists the variables each one reads.

Check every citation the agent returns against the source. citation-management validates metadata, and literature-review documents its search strategy so you can rerun it.
