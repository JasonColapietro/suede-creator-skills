How to choose performance testing skills

Decide whether you need a review or a measurement. Review skills read code for known slow patterns; profiling and benchmark skills run the code and report numbers.

Profiling and benchmark skills need the target running with realistic data. Run them on the same hardware class as production, or the numbers will not transfer.

Record a baseline before the agent changes anything, and ask it to report before and after figures for each change.
