How to choose branding skills

Strategy first, assets second. Positioning and naming skills (obviously-awesome, positioning-statement, naming, product-name) produce decisions; brand kit and asset skills (update-brand-kit, get-brand-assets, visual-brand-extractor) package those decisions for other skills to read.

Asset lookup skills pull logos, colors and fonts from a domain through services such as Brand.dev and list the key they need. Voice extraction skills read your published pages and need only the URLs.

Keep one brand file as the source of truth. Several of these skills write a durable BRAND or brand kit document that copy, ad and social skills read later, which keeps every downstream draft on the same voice.
