How to choose model training skills

Pick the training library you will run, then the skill for it. Hugging Face (TRL, llm-trainer, vision-trainer), Orchestra-Research (Axolotl, Unsloth, PEFT, DeepSpeed) and NVIDIA (NeMo, Megatron Bridge, TAO) each cover the same ground with their own tooling.

Most of these skills expect GPUs. Check the bundled scripts list and SKILL.md for the container, driver and memory requirements, and for managed tuning, the cloud credentials listed under Before you install.

Keep evaluation in the same plan. Pair a training skill with an eval skill so each run reports a score you can compare, and keep a held-out set the training data never touches.
