How to choose SEO skills

Start with scope. Collections such as claude-seo and NotFair split the job into narrow skills (seo-page for one URL, seo-technical for crawlability, seo-local for Google Business Profile), so install the router skill plus the few lanes you actually run.

Check the data source before you install. Skills that read Search Console, GA4 or PageSpeed need a Google credential; the DataForSEO, Ahrefs, SE Ranking and Firecrawl skills need that vendor's key or MCP server; Semrush and Ahrefs metrics in goose-skills come through Apify scrapers. Procedure-only audits need nothing but the page.

Prefer skills that end in a scored, prioritized report or a ready-to-paste fix (JSON-LD, a sitemap, a meta tag set). Those outputs are easy to review and hand to a developer, and they make before-and-after comparisons simple when you rerun the audit.
