How to choose storytelling and fiction skills

Collections such as story-skills keep a story project on disk (characters, timeline, chapters), so install the init skill first and let the others read and update the same files.

Single-skill options such as fiction-studio and novel-writing guide one manuscript from idea to draft in one place. They suit a writer who wants a guided path over a toolkit of separate steps.

These skills need no credentials. The multi-shot storytelling skill in the media category generates images, video and audio through a hosted model service and needs that service's key.
