How to choose customer service skills

Separate the retention playbooks from the operational skills. Churn prevention skills are Markdown procedures for cancel flows, save offers and dunning, so they run with no setup; the support persona skill works inside Gmail and Google Workspace and needs that account authorized.

Signal skills such as the churn risk detector read support tickets, Slack channels and usage data. Check the Before you install panel for the data sources and keys each one expects, and point it at an export first rather than a live inbox.

Pair a detection skill with a writing skill. A risk list is only useful once someone sends the outreach, so pick a win-back or email skill that accepts the account research the detector produces.
