How to choose influencer marketing skills

Vet before you pitch. audience-research and influencer-prospecting score audience fit and authenticity from public data; creator-profile-teardown explains what a creator's best posts have in common.

Profile lookups and searches call third-party scrapers, so check the key each skill lists. Outreach skills such as suede-influencer-outreach work from your offer and the creator's public work and leave sending to you.

For paid creator content, the ugc skill plans direct-to-camera ads and generates them through fal.ai media models, which requires a fal API key and usage billing on that account.
