How to choose authentication skills

Use your identity provider's own skill when there is one. Firebase, AWS, Google, Neon and Microsoft skills follow that provider's current setup.

These skills touch secrets. Check the environment variables listed under Before you install and keep client secrets out of source control.

Pair an implementation skill with a security review skill before shipping a new login flow.
