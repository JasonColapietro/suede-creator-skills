How to choose Azure skills

Start with Microsoft's azure-prepare, azure-validate and azure-deploy skills for a new deployment; they walk an agent from an app folder to running resources with azd.

Azure skills run az and azd commands with your signed-in identity. Confirm the subscription before the agent acts, and use resource groups you can delete.

For cost and governance, the cost-analysis, cost-optimization and advisor skills read billing and Advisor data, so they need Reader or Cost Management access on the subscription.
