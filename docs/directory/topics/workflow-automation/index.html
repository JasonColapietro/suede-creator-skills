How to choose workflow automation skills

Pick by platform. The FlowStudio skills cover Power Automate end to end and need the FlowStudio MCP server; the Google Workflow skills chain Gmail, Calendar, Drive and Tasks through the gws CLI.

Some automation skills require a paid tier. The FlowStudio monitoring skill states a Pro+ subscription, and the Before you install panel shows the keys each skill reads.

Run new flows on test data first. Automations repeat their actions on every trigger, so confirm one run end to end before turning on a schedule.
