How to choose content marketing skills

Separate planning from production. Strategy and cluster skills (content-strategy, topic-cluster-planning, topical-authority-mapper) produce a map; brief skills (content-brief, seo-content-brief, content-brief-factory) produce writer-ready instructions for one piece at a time.

Check the inputs each brief skill needs. Some read the live top ten results for a keyword through a search or scraping service; content-planner works from your Search Console data; strategy skills work from the audience and product context you supply.

Choose skills that tie every recommendation to a KPI or a search query. A calendar that names the query each piece targets is far easier to measure and prune than a list of topic ideas.
