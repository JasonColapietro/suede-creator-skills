How to choose prompt engineering skills

Match the skill to the prompt's target. General optimizers (prompt-optimizer, system-prompt-creator, prompt-engineer) work across models; fal-prompting and Replicate's prompt-images and prompt-videos encode the conventions of specific media models.

For prompts already in production, pick a skill that works from evidence. arize-prompt-optimization uses traces and evaluations, and test-prompt runs the prompt against cases before you commit a change.

Most prompt skills are plain Markdown with no scripts, so you can read the whole method in SKILL.md before installing. The platform skills (Arize, Agent Platform) read service credentials, shown under Before you install.
