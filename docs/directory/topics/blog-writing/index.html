How to choose blog skills

The claude-blog family in dev-gtm-claude-skills splits the job into many lanes behind one router; install the router and the lanes you use. Single-skill options such as write-content, content-writer and make-blog-post produce a full article in one pass.

Hosted options such as appie-article-writer and timetopost-autoseo-blog draft through their service and need that account's API key. Local skills work from your brief and any research they fetch.

Run a fact-check pass before publishing. blog-factcheck fetches cited sources and checks that each number actually appears there.
