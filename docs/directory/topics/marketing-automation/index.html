How to choose marketing automation skills

Lifecycle skills (emails, suede-emails, lifecycle-messaging) design triggered sequences; SMS skills cover welcome, cart recovery and win-back flows with consent and quiet-hours rules; marketing-loops and suede-marketing-loops define a repeatable loop with cadence, conditions and stored state.

These skills design the automation; your email service, SMS provider or scheduler runs it. Check each flow's consent and opt-out handling before it goes live.

Start small. Automate one loop with a clear trigger and success metric, review its first runs by hand, then add the next.
