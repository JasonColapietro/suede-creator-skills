How to choose PDF skills

Local skills (pdf, pdftk, make-pdf, nano-pdf) run bundled scripts or a command-line tool on your machine. Install the tool each one names, such as pdftk or the nano-pdf CLI.

Nutrient handles OCR, redaction and signing through its hosted processor and reads an API key. Use it when you need those operations at production quality.

Ask the agent to render and check the PDF it produced. Skills that compare the visual output catch layout problems that text extraction misses.
