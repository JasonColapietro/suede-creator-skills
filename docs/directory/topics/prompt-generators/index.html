How to choose prompt skills

Split model prompts from media prompts. System prompt and optimizer skills target LLM agents; Replicate, fal.ai and Vibe Creating skills teach the prompt patterns that image and video models respond to.

Optimization skills that use production traces, such as the Arize skill, need access to that platform. The Before you install panel lists the variables they read.

Test before you adopt. Run a rewritten prompt and the original on the same inputs, and keep the version that produces better results on your own cases.
