How to choose animation and motion graphics skills

Pick a framework and stay in it. HyperFrames skills form a set with one entry skill; Remotion skills use React. A port skill moves Remotion work to HyperFrames.

These skills render locally with Node and a headless browser, so check the runtime requirements.

For small looping assets, the Slack GIF and sticker skills cover size and frame limits.
