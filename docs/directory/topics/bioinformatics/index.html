How to choose bioinformatics skills

Most skills wrap one library or database. Choose by the tool your lab already uses, since the skill encodes that tool's file formats and defaults.

NVIDIA NIM skills (OpenFold, ProteinMPNN, RFDiffusion, Evo 2, MSA search) send sequences to NVIDIA-hosted endpoints and read an NGC API key. Several state this at the top of their description; check it against your data policy.

Pipelines such as Nextflow, Parabricks and DNAnexus run long jobs on compute you pay for. Start with a small sample and confirm outputs before a full run.
