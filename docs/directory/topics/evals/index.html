How to choose eval skills

Decide what you are scoring. Benchmark harnesses (evaluating-llms-harness, nemo-evaluator-sdk, evaluating-code-models) rank models on public datasets; eval-driven development and agent evaluation skills build test sets from your own application.

Platform evaluators on Arize, Phoenix and Google's Agent Platform store results in that service and read its API key. Local harnesses run on your hardware and may need a GPU, which the bundled scripts list shows.

For skills and prompts, use an eval that compares against a baseline. test-skill and skill-creator run the task with and without the change, so you see what the change actually did.
