How to choose scheduling skills

Almost every scheduling skill works through Google Calendar, either with the gws CLI or the Calendar API, so authorize one Google account and use it across the set.

The Google Workspace recipes are single tasks (find free time, block focus time, reschedule a meeting). Install the ones you repeat each week, and use the full calendar skill for anything else.

Changes notify attendees. Ask the agent to show the event before it saves, especially for recurring events and reschedules.
