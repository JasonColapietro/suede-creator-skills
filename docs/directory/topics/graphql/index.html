How to choose GraphQL skills

Start with Apollo's Official skills for any Apollo stack; they track Apollo Server 5 and Client 4.

Router and Rover skills work against GraphOS. Publishing schemas needs an Apollo graph API key, read from your environment.

For gRPC, use protobuf-grpc-api-review to check wire compatibility before you merge a .proto change.
