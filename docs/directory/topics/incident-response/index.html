How to choose incident response skills

During an incident, use an investigation skill tied to your platform (AWS DevOps Agent, CloudWatch investigation, AKS troubleshooting); after it, use a postmortem skill so the write-up follows a consistent format.

Investigation skills read logs and metrics with your credentials. Grant read access only, so the agent can gather evidence while people make the changes.

Chaos and resilience skills (chaos engineering, mirrord chaos, Resilience Hub) inject faults on purpose. Run them in staging with a clear stop condition.
