How to choose security audit skills

Start with a review skill matched to the code you ship (general security review, GitHub Actions, Django, Rust or C), then add threat modeling for new features with a trust boundary.

Cloud posture and SecOps skills from AWS and Google query security services in your account and need the matching permissions, listed under Before you install.

Trail of Bits publishes a deep set (differential review, variant analysis, sharp edges, constant-time checks). These run static analysis tools, so install CodeQL or Semgrep where the agent works.
