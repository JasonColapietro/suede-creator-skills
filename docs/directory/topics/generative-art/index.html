How to choose generative art skills

Algorithmic art skills write p5.js with seeded randomness, so the same seed reproduces the same piece. No API key is needed.

Shader skills teach GLSL techniques such as ray marching and particle systems; expect to run the result in a browser or engine.

For cover art, the album art director writes prompts you take to an image model.
