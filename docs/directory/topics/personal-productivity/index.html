How to choose personal productivity skills

Calendar skills act on your Google account through the Workspace CLI; check permissions before they create events.

The personal context skill writes Markdown files about how you work, so keep them in a private folder.

Pick one capture method and one focus method, and use them daily rather than stacking overlapping skills.
