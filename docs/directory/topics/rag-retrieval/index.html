How to choose RAG skills

Choose by where your documents live and which stack you run. Framework skills (langchain-rag, llamaindex) fit an app you are writing; platform skills (RAG Engine, Foundry IQ, NVIDIA RAG Blueprint) manage a hosted corpus for you.

Retrieval quality is mostly embedding and chunking choices. rag-architect and the sentence-transformers skills cover those decisions, and rag-eval measures the result before you tune further.

Ingestion skills such as firecrawl-knowledge-base call a crawling service and read its API key. Respect each site's terms and keep the source list you crawl.
