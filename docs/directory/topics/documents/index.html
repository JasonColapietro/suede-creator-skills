How to choose document skills

Choose by output. DOCX skills produce Word files with styles, tables and tracked changes; Google Docs skills write to Drive; conversion skills turn documents into Markdown so an agent can read them.

Parsing skills differ in setup. MarkItDown and LiteParse run locally, Firecrawl parse calls its API, and Nutrient uses its processing service; the Before you install panel lists each one's requirements.

Check the license on each page. The Anthropic document skills use proprietary terms that restrict copying, and the directory shows that in place of install commands.
