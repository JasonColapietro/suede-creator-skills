How to choose game development skills

Match the engine. The Unity and Unreal skill, the web engine skill and the Minecraft plugin skill each target a different runtime and do not substitute for one another.

Asset generation through fal.ai calls a hosted model and reads an API key; usage is billed by that provider.

Engine work benefits from a run-and-check loop. Ask the agent to build and launch the game after changes rather than reviewing code alone.
