How to choose infrastructure as code skills

Match the tool you already use. HashiCorp publishes skills for Terraform style, tests, stacks, policy and provider development; AWS covers CDK and CloudFormation; Microsoft and HashiCorp cover Azure Verified Modules and Bicep.

Keep the agent on plan before apply. IaC skills can run terraform or cdk commands that change real resources, so review the plan output and use a non-production workspace or state file.

Provider-development skills are for teams writing a Terraform provider in Go; most readers want the module, testing and import skills instead.
