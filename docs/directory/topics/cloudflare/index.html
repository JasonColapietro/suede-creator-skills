How to choose Cloudflare skills

For Workers projects, install workers-best-practices and wrangler together; the first sets code rules, the second covers config, bindings and deploys.

Wrangler and the Cloudflare CLI need an API token or a logged-in session. Scope the token to the account and zones the agent should touch.

Zero trust migrations (Cloudflare One) change network access for a whole organization. Run them as a reviewed plan, and keep a rollback path.
