How to choose agent tracing skills

For your own LLM app, pick the tracing platform you will keep. Arize, Phoenix and LangSmith each have instrumentation plus trace-reading skills; installing both halves from one vendor gives the agent a full loop from capture to diagnosis.

For coding-agent sessions, local tools such as agenttrace, session-report and conversation-analyzer read history files already on your machine and need no service account.

Hosted tracing sends prompts and outputs to the vendor. Check the environment variables under Before you install and the vendor's data retention settings before you trace production traffic.
