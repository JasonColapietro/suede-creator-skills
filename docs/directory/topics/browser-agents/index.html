How to choose browser agent skills

Decide between a local browser and a hosted one. Local CLIs (agent-browser, dev-browser, Playwright) run on your machine; Browserbase, Browser Use Cloud and Notte run remote sessions and read an API key shown under Before you install.

For sites you own, consider WebMCP skills (add-webmcp, webmcp-gen, webmcpify). Exposing real tools is more reliable than having an agent click through the interface.

Browsing agents act with whatever session they hold. Use safe-browser's domain allowlist or a separate browser profile, and avoid importing personal cookies into automation you do not supervise.
