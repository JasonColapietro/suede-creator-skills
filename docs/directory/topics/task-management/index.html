How to choose task management skills

Choose where tasks live. Google Tasks skills need Workspace access through the gws CLI, team goal skills write to the Hivemind Deeplake filesystem, and capture and action plan skills produce Markdown you can paste anywhere.

Thinking skills such as unblock action and capture are plain Markdown with no setup, so they are the fastest way to get a messy list into a clear next step.

Keep one system of record. Use these skills to feed the tracker you already check every day, rather than starting a second list the agent maintains alone.
