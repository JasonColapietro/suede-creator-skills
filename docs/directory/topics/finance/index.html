How to choose finance and accounting skills

Match the skill to the money you are tracking. SaaS metric and pricing skills are Markdown references with formulas and benchmarks; cloud cost skills query AWS, Azure, GKE billing or the hosted Costory MCP; budget skills build Excel or Google Sheets workbooks you own.

Market data and crypto skills call live APIs such as CoinPaprika, Octav or EmblemVault, and some can sign transactions. Read the Before you install panel for keys and tool permissions, and keep wallet skills in review-first mode until you trust them.

Keep a qualified reviewer on anything that files, pays or trades. These skills structure the analysis and the numbers; the decision and the signature stay with you.
