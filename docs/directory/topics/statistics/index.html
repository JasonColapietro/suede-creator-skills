How to choose statistics skills

Plan before you collect. experimental-design and statistical-power fix the design and sample size up front, and the A/B testing skills do the same for product experiments.

For analysis, statistical-analysis walks through test choice and assumptions; statsmodels, PyMC and scikit-survival cover specific model families in Python.

These skills run Python against your data. Check the scripts list on each page and keep raw data unchanged so every result can be reproduced.
