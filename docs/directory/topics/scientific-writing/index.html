How to choose scientific writing skills

Start from the venue. ml-paper-writing and systems-paper-writing carry section blueprints for specific conferences, and venue-templates formats manuscripts for named journals.

Figure and poster skills run code. academic-plotting and scientific-visualization use Python plotting libraries, and latex-posters needs a LaTeX install; the scripts list on each page shows what runs.

Keep authorship decisions with the authors. Use peer-review and scholar-evaluation drafts as structured input to your own judgment, and disclose AI assistance where your venue requires it.
