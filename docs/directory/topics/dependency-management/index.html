How to choose dependency management skills

Separate upgrade skills from audit skills. Upgrade skills move one framework or SDK to a new version with its migration steps; audit skills assess the risk of what you already depend on.

Upgrade skills change lockfiles and build config. Run them on a branch with CI, and upgrade one major version at a time.

Publishing skills (PyPI, release-it) need registry credentials and push public artifacts, so keep the final publish step under your control.
