How to choose image editing skills

For mechanical work such as resizing, cropping, format conversion and watermarks, start with a local skill built on Pillow or ImageMagick. It needs no API key and gives the same result every run.

For edits described in words (change the scene, swap a background, merge several pictures), choose a skill that calls a hosted edit model and confirm you have that provider's key.

Specialist skills cover narrow jobs well: Bria's automotive skill handles vehicle photos, and its ad tools resize or layer a finished ad. Use them when your input matches their focus.
