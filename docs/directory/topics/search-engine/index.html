How to choose web search skills

Each search skill wraps one provider and reads that provider's API key, shown under Before you install. Pick the provider you already pay for, or one with a free tier for testing.

Choose by result type. SERP skills return ranked links and metadata, neural and research skills return extracted page content, and deep research modes return a cited report.

Install one primary search skill so the agent uses it consistently. Add a second only for a specific need, such as scholarly results or shopping data.
