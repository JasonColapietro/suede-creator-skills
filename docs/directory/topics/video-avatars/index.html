How to choose video avatar skills

Generation skills need hosted credits (GooseWorks, fal.ai or Tavus), so check costs before long scripts.

Use a review skill after rendering. The UGC review gate transcribes the output and compares it with the approved script.

Get consent before you clone a real person's face or voice.
