How to choose research skills

Match the skill to the evidence you need. Scientific skills from K-Dense-AI and Orchestra-Research work from papers and databases; general researchers (deep-research, firecrawl-deep-research, the bitwize-music researchers) work from the open web and primary sources.

Search-backed skills call a provider (Firecrawl, SerpApi, OpenAI, Gemini) and read its API key, shown under Before you install. Usage is billed by that provider.

Prefer skills that cite sources and separate fact from inference. autonomous-investigation and research-lookup structure their output that way, which makes review fast.
