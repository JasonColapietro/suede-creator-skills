How to choose serverless skills

Start from the platform you deploy to. Most listings here come from AWS's own agent toolkit and cover one Lambda task each (durable functions, VPC internet access, DynamoDB connections, timeout debugging), so install the few that match your stack rather than the whole set.

These skills run cloud CLIs against your account. Check the Before you install panel for the credentials each one reads, and point the agent at a sandbox account or a dev stage before production.

For GPU or batch jobs, the Modal skills package functions as containers billed per second; they need a Modal token, while the Cloud Run and Lambda skills use your existing gcloud or AWS login.
