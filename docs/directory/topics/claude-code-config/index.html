How to choose Claude Code setup skills

Start with the instruction file. agents-md, claude-md-improver, init and review-claudemd keep CLAUDE.md or AGENTS.md short and accurate, which affects every task in that repository.

Hooks run code on every matching event. hook-development and git-guardrails-claude-code explain the event types; test a new hook in one project before you add it to global settings.

Plugin and command skills from anthropics/claude-plugins-official follow Claude Code's current plugin format. Use them when you package commands, agents and hooks for a team rather than editing settings by hand.
