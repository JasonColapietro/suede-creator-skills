How to choose diagram and infographic skills

Choose by output format. Mermaid and PlantUML skills write text that renders in docs; draw.io and Excalidraw skills write editable files; HTML diagram skills produce standalone pages.

Code-aware skills such as Trail of Bits diagramming read your repository and draw call graphs or protocol flows from it.

Infographic and scientific schematic skills call Nano Banana through OpenRouter, so they need a key.
