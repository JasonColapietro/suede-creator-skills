How to choose AI video generation skills

Most skills call one hosted service (fal.ai, Venice, Replicate or NVIDIA), and video generation costs more per call than images. Confirm keys and budgets first.

Prompt skills help any model; endpoint skills run the job. Pair one of each.

For a full production flow with review gates, the Orkas VideoStudio router sends a brief to generation, composition or editing.
