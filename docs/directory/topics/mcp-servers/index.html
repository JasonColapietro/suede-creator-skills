How to choose MCP skills

Separate builder skills from user skills. Builder skills (mcp-builder, build-mcp-server, the language generators) help you write a server; user skills teach an agent to work through an existing server and usually name it in SKILL.md.

Skills that use a hosted MCP server need that server configured and authorized in your client first. The Before you install panel flags MCP mentions; read SKILL.md for the server URL and the scopes it asks for.

Before you ship a server, run a review skill such as mcp-security-audit, mcp-implementation-security-review or mcp-release-qa. They check configuration, tool handlers and a live protocol session against named criteria.
