How to choose physics skills

Choose by framework and hardware. Qiskit targets IBM Quantum, Cirq targets Google Quantum AI, and CUDA-Q targets NVIDIA GPUs and QPUs; each skill follows its own SDK version.

Weather and climate skills from Earth2Studio split the work into install, data fetch, model wrappers and forecasts. Install them as a set so they hand off cleanly.

For calculations people will rely on, add uncertainty-and-units or SymPy so units and exact results are checked, and keep the script that produced each number.
