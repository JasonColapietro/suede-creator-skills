How to choose CI/CD skills

Pick by CI system first. GitHub Actions has the deepest coverage here, from writing workflow specs to hardening against injection and upgrading runtime versions; Azure DevOps, Cloud Build and Expo EAS each have their own skills.

Pair a pipeline-writing skill with a security one. Workflow files run with repository secrets, and the Actions hardening and security-review skills check for untrusted input, broad tokens and unpinned actions.

Skills that fix failing CI (gh-fix-ci, ci-speedup) read run logs through the gh CLI. Make sure gh is installed and authenticated, and let the agent propose the fix on a branch.
