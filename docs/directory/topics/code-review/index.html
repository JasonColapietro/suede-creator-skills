How to choose code review skills

Choose a review skill whose checks match what your team blocks merges on. Some focus on bugs, some on security, some on database code; pair a general reviewer with one specialist.

Skills that read pull requests use the gh CLI or a GitHub token, listed under Before you install. Local-diff reviewers need no account and work before you push.

Review skills for the author side (receiving review, resolving comments, iterating a PR) help the agent respond to feedback; they sit well next to a reviewer skill.
