How to choose startup skills

Use canvas and strategy skills early. Lean canvas, startup canvas and beachhead skills are Markdown frameworks that turn a raw idea into a one-page plan you can test.

Fundraising skills research investors and prepare calls. Some pull meetings from Google Calendar and enrich investor profiles with paid data sources, so check the variables listed under Before you install.

Guided journey skills orchestrate several frameworks in sequence. Install the whole collection they call, and run one journey end to end before adding standalone skills that cover the same step.
