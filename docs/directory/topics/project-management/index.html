How to choose project management skills

Start with your tracker. The Atlassian, Jira and Linear skills read and write real tickets through their APIs or an MCP server, so set up the credential listed under Before you install and test on a sandbox project.

Planning skills (sprint plans, retros, OKRs, roadmaps) are Markdown templates. Pick the collection whose format matches how your team already writes these documents, and install its related skills together.

Copilot skills such as the project manager and scrum master personas cover the whole loop. Use one of them as the default and add single-purpose skills only where your process needs more depth.
