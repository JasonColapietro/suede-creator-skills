How to choose web scraping skills

Decide between hosted and local. Firecrawl, Browserbase, Browser Use Cloud and Apify run in the vendor's cloud and need an API key; Puppeteer, dev-browser and agent-browser run a local browser.

Check each site's terms and robots rules before scraping at volume, and prefer the vendor's rate controls.

Cookie sync and remote-browser skills carry your logged-in sessions; use a separate browser profile for agent work.
