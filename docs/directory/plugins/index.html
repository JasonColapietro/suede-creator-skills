Claude Code plugins and mods

Directory / Claude Code plugins and mods

A plugin is a folder of skills, agents, hooks and MCP servers that Claude Code installs as one unit. A mod is a plugin whose JavaScript or TypeScript handlers run inside Claude Code itself, so it can draw panes, add commands and guard tool calls.

  • 22 listed repositories
  • 7 from official publishers
  • 3 sections

Plugins install from a marketplace with /plugin install name@marketplace, or from a repository with /plugin marketplace add owner/repo. Anthropic's own marketplace is added on the first interactive session; everything else is a catalog you add yourself.

Mods are the same package with one extra file: hooks/hooks.json names a modules entry, and the module exports a register function that subscribes to events such as tool calls, prompt submissions and interface draws. Claude Code 2.1.287 or later runs them. They are not sandboxed: a mod runs with your permissions, so read what it registers before you install it.

How a plugin installs

Inside Claude Code, add a marketplace once, then install plugins from it. The same commands work from the shell as claude plugin marketplace add and claude plugin install. Validate a mod before installing it with claude plugin validate, which prints the hooks it registers and the calls it makes.

Commands
/plugin marketplace add owner/repo
/plugin install plugin-name@marketplace-name
claude plugin validate ./some-mod

Questions and answers

What is the difference between a plugin and a mod?

A plugin is a folder of components that Claude Code installs as one unit: skills, agents, settings hooks, MCP servers and language servers. A mod is a plugin that also ships a hooks module, JavaScript or TypeScript code that runs inside Claude Code and can draw interface elements, add commands and change tool calls.

How do I install a Claude Code plugin?

Add its marketplace with /plugin marketplace add owner/repo, then run /plugin install name@marketplace. Anthropic's claude-plugins-official marketplace is already present on the first interactive session. From a shell, the same commands are claude plugin marketplace add and claude plugin install.

Are mods safe to install?

A mod runs with your permissions and is not sandboxed. Run claude plugin validate on the folder first: it prints the hooks the mod registers and the calls it makes. Prefer mods from publishers you know, and read the register module before enabling it.

Does the directory grade plugins and mods?

No. The Suede Skill Check scores skills from their SKILL.md folders. Plugins and mods are listed from their publisher's repository with a short description; they carry no score, no security result and no verification badge.
