About this register

Applied records the public request and its original scope. Reviewed links to a published review record. Directory listing counts only requested skills in the current scored catalog. Featured is an editorial placement, which can be granted independently of a quality grade. A Directory member is a separate placement.

Issue open/closed state is shown for reference, not as a review verdict. Reviews describe their checked snapshot and findings; an editorial feature or badge is not a security certification. A selected-skill request does not cover the rest of a repository or future additions.

This register covers public GitHub listing applications, including requests submitted with AI assistance. Discovered projects and private email or message submissions are not automatically included. Applicant names are the public GitHub handles on their source issues; a handle may represent a person, team or automation. Private contact details and profile data are not republished here. Repeat requests retain their own source issue; they do not create extra directory listings.
