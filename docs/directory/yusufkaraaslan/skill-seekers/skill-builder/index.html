Install skill-builder

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/yusufkaraaslan/Skill_Seekers/tree/development/distribution/claude-plugin/skills/skill-builder
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 --branch development https://github.com/yusufkaraaslan/Skill_Seekers.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"distribution/claude-plugin/skills/skill-builder .claude/skills/
rm -rf "$tmp"
Codex installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo yusufkaraaslan/Skill_Seekers \
    --path distribution/claude-plugin/skills/skill-builder \
    --ref development
