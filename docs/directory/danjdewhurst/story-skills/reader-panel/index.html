Directory summary

reader-panel simulates a beta read with reader personas, showing how genre readers might react and whether they would keep reading before real beta readers. Listed in Writing and Editing, it is built for Claude Code users working on writing and editing. It scores 90/100, grade A, on the Suede Skill Check, with full points for structural checks, recent maintenance and instruction depth. danjdewhurst publishes it under MIT, an open-source or open-content license, so you can use and adapt it at no cost under those terms. It installs in Claude Code, Codex, Cursor and other agents that read the Agent Skills format.

How the author describes it

This skill should be used when the user asks for a "simulated beta read", "reader panel", "persona read", "first read before my beta readers", "how would a genre reader react", "would a reader keep going", "pre-beta read", "mock beta readers", or wants structured persona reads of a chapter range before human readers see it. NOT for real reader feedback (use feedback-triage), a paid sensitivity or authenticity read (use editorial-review), or the agent's own line edit (use line-editing).
