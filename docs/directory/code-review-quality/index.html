Code Review and Code Quality agent skills

Directory / Code Review and Code Quality

Skills for reviewing pull requests, refactoring, linting and enforcing code standards. They turn review into a repeatable pass with named checks, so findings are consistent across every change.

How to choose code review and code quality skills

Pick a review skill whose checks match what your team blocks merges on. A review that reports what you would fix is more useful than a long generic list.

Language-specific review skills catch idioms a general reviewer misses; pair one with a general review skill rather than replacing it.

Refactoring skills change many files. Run them on a branch with tests, and ask for the change in small, reviewable steps.
