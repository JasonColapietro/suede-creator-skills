Install brainstorm

The skills CLI works with Claude Code, Codex, Cursor and other agents; the other routes copy the folder by hand.

Skills CLI
npx skills add https://github.com/NeoLabHQ/context-engineering-kit/tree/master/skills/brainstorm
Claude Code, project-level copy
tmp="$(mktemp -d)"
git clone --depth 1 --branch master https://github.com/NeoLabHQ/context-engineering-kit.git "$tmp/repo"
mkdir -p .claude/skills
cp -R "$tmp/repo/"skills/brainstorm .claude/skills/
rm -rf "$tmp"
Codex installer
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo NeoLabHQ/context-engineering-kit \
    --path skills/brainstorm \
