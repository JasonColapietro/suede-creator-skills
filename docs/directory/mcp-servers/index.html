MCP servers

Directory / MCP servers

A Model Context Protocol server gives an agent access to a system it cannot reach on its own: a browser, a database, a billing API. A skill teaches the method; a server supplies the tools. The best setups pair the two.

  • 6 listed repositories
  • 5 from official publishers
  • 2 sections

Claude Code reads servers from .mcp.json in a project or from a plugin's mcpServers entry; Cursor, Codex, Gemini CLI, Goose and Grok Build have their own configuration files for the same servers. The official registry publishes a server.json for each listed server with a verified namespace.

A server holds credentials and acts on outside systems, so check what tools it exposes and what scopes its keys carry before you add it. The directory lists servers from their publisher's repository and does not score or scan them.

How a server installs

Add the server to your agent's configuration. In Claude Code, claude mcp add registers a command or URL; a project can also commit a .mcp.json file so every collaborator gets the same servers.

Commands
claude mcp add <name> -- npx -y <package>
claude mcp add --transport http <name> <url>

Questions and answers

What is an MCP server?

A program that speaks the Model Context Protocol and exposes tools an agent can call, resources it can read and prompts it can use. It usually holds the credentials for an outside service, such as a database or a billing API.

Should I use a skill or an MCP server?

Use a skill when the agent has the access it needs and is missing the method. Use a server when the job needs data or actions the agent cannot reach with files and a shell. Many featured projects in this directory pair a server with the skills that know how to use it.

How do I add a server to Claude Code?

Run claude mcp add with the server's command or URL, or commit a .mcp.json file in the project. Plugins can also declare servers, so one install brings the skills and the tools together.

Are the servers here scanned or scored?

No. Servers are listed from their publisher's repository with a short description. They carry no quality score, no security result and no verification badge from the directory.
