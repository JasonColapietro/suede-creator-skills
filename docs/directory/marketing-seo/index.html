How to choose marketing and SEO skills

For SEO work, pair an audit skill with a content skill from the same collection when you can. Collections share vocabulary, so the brief the audit produces is the input the writing skill expects.

Read the output format in each SKILL.md. Skills that end in a checklist, a scored audit or a ready-to-paste draft are easy to review; open-ended ones need a clearer prompt from you.
