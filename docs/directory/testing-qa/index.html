How to choose testing and QA skills

Pick by test runner. A skill written for your framework (Playwright, Jest, pytest and so on) produces tests that run in your CI without translation.

Debugging skills that prescribe a method, such as reproducing first and tracing to the root cause, pay off across every task, not just one.

Browser and device-cloud skills may need a vendor account; the Before you install panel lists the environment variables their code reads.
