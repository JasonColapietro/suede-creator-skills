stage-decide 83/100 · B

Publisher's task description: The decision layer for real footage — understand → select → produce an EVIDENCE-bearing rough cut. Trigger when the EDIT task is "find / select / reduce / clean" (remove dead air, drop fillers, pick highlights, cut 1 hour to 3 minutes), NOT executing a known timecode edit (that is stage-edit). Deterministic auto-cuts (silence/filler/quality) are reliable; narrative/emotional selection is a low-confidence DRAFT for the user to review.
