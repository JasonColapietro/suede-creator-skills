How to choose DevOps and cloud skills

Prefer the platform's own skills. Cloud and infrastructure vendors publish skills that follow their current CLI and API, and the directory marks them Official.

These skills act on real infrastructure. Check the tool permissions and environment variables listed under Before you install, and run them first against a staging account.

For infrastructure as code, keep the skill and your module versions in step; a skill written for an older provider version can suggest arguments that no longer exist.
