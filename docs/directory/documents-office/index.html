How to choose documents and office files skills

Check the license first. Some widely used document skills are published under proprietary terms that restrict copying, and their pages say so in place of install commands.

Document skills rely on bundled scripts and Python or Node libraries; the scripts list on each page shows what will run.

Ask the agent to open and check the file it produced. Skills that verify output catch formatting problems a text-only answer hides.
