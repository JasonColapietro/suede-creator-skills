Show readers your skill’s Suede Skill Check score right in your README. Each badge links to your listing, with the score breakdown, license, source and install command.

Two shields for skills scoring 80–99

Grade A (90–99) shows a gold shield; grade B (80–89) shows the standard shield. Each skill also gets a numeric score shield. In the 2026-10-22 snapshot, 1,724 third-party skills qualify: 120 at grade A and 1,604 at grade B, across 109 repositories.

Add your badge in three steps

  1. Find your skill. Search the directory or run the free skill check with your repository URL.
  2. Copy the snippet. Every eligible listing has a Badge section with Markdown and HTML for the score shield, the grade shield, or both.
  3. Paste it into your README. The image updates when the directory refreshes, so the badge always shows your current score.

Display a linked badge, then request badge verification: eligible verified skills can receive a featured placement while the offer is open.
