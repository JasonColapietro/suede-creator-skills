Questions and answers

Which data analysis skill has the highest Suede Skill Check score?

scientific-visualization from K-Dense-AI/claude-scientific-skills scores 89/100, grade B, the highest of the 15 listed data analysis skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. google-cloud-solution-agentic-ai-data-science-workflow from google/skills follows at 87/100.

How do I install a data analysis skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For scientific-visualization, run: npx skills add https://github.com/K-Dense-AI/claude-scientific-skills/tree/main/skills/scientific-visualization. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these data analysis skills free?

All 12 data analysis skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by Apache-2.0 (6), MIT (4), BSD-3-Clause (1) and CC-BY-4.0 AND Apache-2.0 (1), so you can use and adapt the files at no cost under those terms.

Do these data analysis skills work with Codex and Cursor?

Yes. Each of the 12 data analysis skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 3 of them declare compatibility in the SKILL.md frontmatter.

How does SuedeAI.directory rank data analysis skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files. A skill joins this page when its name or summary matches the data analysis keyword map; each repository fills at most three rows, so the table compares publishers.
