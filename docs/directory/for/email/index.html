How do I install a email skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For cold-email, run: npx skills add https://github.com/coreyhaines31/marketingskills/tree/main/skills/cold-email. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.
