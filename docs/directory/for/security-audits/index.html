Questions and answers

Which security audit skill has the highest Suede Skill Check score?

codeql from trailofbits/skills scores 92/100, grade A, the highest of the 56 listed security audit skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and curated-list citations. semgrep from trailofbits/skills follows at 92/100.

How do I install a security audit skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For codeql, run: npx skills add https://github.com/trailofbits/skills/tree/main/plugins/static-analysis/skills/codeql. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these security audit skills free?

All 15 security audit skills on this page are published in public GitHub repositories and cost nothing to download. 14 use an open-source or open-content license, led by Apache-2.0 (5), MIT (5) and CC-BY-SA-4.0 (4), so you can use and adapt the files at no cost under those terms. claude-security is published under the publisher's own terms, which restrict copying; read them before you install. 2 skills name credentials for an outside service; each full page lists them under Before you install.

Do these security audit skills work with Codex and Cursor?

Yes. Each of the 15 security audit skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs 14 of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. claude-security follows the publisher's own install route, shown on its page.
