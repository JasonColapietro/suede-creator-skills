Which Kubernetes skill has the highest Suede Skill Check score?

gke-ai-troubleshooting-jobset-interruption from google/skills scores 89/100, grade B, the highest of the 69 listed Kubernetes skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. gke-ai-troubleshooting-tpu-dynamic-slices-monitoring from google/skills follows at 89/100.

How do I install a Kubernetes skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For gke-ai-troubleshooting-jobset-interruption, run: npx skills add https://github.com/google/skills/tree/main/skills/cloud/gke-ai-troubleshooting-jobset-interruption. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these Kubernetes skills free?

All 15 Kubernetes skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (8) and Apache-2.0 (7), so you can use and adapt the files at no cost under those terms. One skill names credentials for an outside service; each full page lists them under Before you install.

Do these Kubernetes skills work with Codex and Cursor?

Yes. Each of the 15 Kubernetes skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 2 of them declare compatibility in the SKILL.md frontmatter.

How does SuedeAI.directory rank Kubernetes skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files. A skill joins this page when its name or summary matches the Kubernetes keyword map; each repository fills at most three rows, so the table compares publishers.
