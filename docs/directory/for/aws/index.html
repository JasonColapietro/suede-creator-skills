Questions and answers

Which AWS skill has the highest Suede Skill Check score?

agents-deploy from aws/agent-toolkit-for-aws scores 89/100, grade B, the highest of the 92 listed AWS skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. aws-sst-development from zxkane/aws-skills follows at 86/100.

How do I install an AWS skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For agents-deploy, run: npx skills add https://github.com/aws/agent-toolkit-for-aws/tree/main/plugins/aws-agents/skills/agents-deploy. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these AWS skills free?

All 15 AWS skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (8), Apache-2.0 (6) and MPL-2.0 (1), so you can use and adapt the files at no cost under those terms.

Do these AWS skills work with Codex and Cursor?

Yes. Each of the 15 AWS skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex.

How does SuedeAI.directory rank AWS skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files. A skill joins this page when its name or summary matches the AWS keyword map; each repository fills at most three rows, so the table compares publishers.
