Which SQL skill has the highest Suede Skill Check score?

go-database from eduardo-sl/go-agent-skills scores 95/100, grade A, the highest of the 59 listed SQL skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. cloud-databases-onboarding from google/skills follows at 92/100.

How do I install an SQL skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For go-database, run: npx skills add https://github.com/eduardo-sl/go-agent-skills/tree/main/skills/(data)/go-database. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these SQL skills free?

All 15 SQL skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by Apache-2.0 (10) and MIT (5), so you can use and adapt the files at no cost under those terms.

Do these SQL skills work with Codex and Cursor?

Yes. Each of the 15 SQL skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. go-database declares compatibility in the SKILL.md frontmatter.
