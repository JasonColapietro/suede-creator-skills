Questions and answers

Which React skill has the highest Suede Skill Check score?

scaffold-nextjs from mblode/agent-skills scores 89/100, grade B, the highest of the 40 listed React skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. web-artifacts-builder from anthropics/skills follows at 87/100.

How do I install a React skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For scaffold-nextjs, run: npx skills add https://github.com/mblode/agent-skills/tree/main/skills/scaffold-nextjs. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these React skills free?

All 15 React skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (14) and Apache-2.0 (1), so you can use and adapt the files at no cost under those terms. 2 skills name credentials for an outside service; each full page lists them under Before you install.

Do these React skills work with Codex and Cursor?

Yes. Each of the 15 React skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 4 of them declare compatibility in the SKILL.md frontmatter.
