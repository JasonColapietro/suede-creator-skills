Questions and answers

Which video skill has the highest Suede Skill Check score?

youtube-api from ZeroPointRepo/youtube-skills scores 90/100, grade A, the highest of the 89 listed video skills in the October 22, 2026 snapshot. It earns full points for structural checks, curated-list citations and instruction depth. youtube-channels from ZeroPointRepo/youtube-skills follows at 90/100.

How do I install a video skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For youtube-api, run: npx skills add https://github.com/ZeroPointRepo/youtube-skills/tree/main/clawhub/youtube-api. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these video skills free?

All 15 video skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (12), Apache-2.0 (2) and CC0-1.0 (1), so you can use and adapt the files at no cost under those terms. 5 skills name credentials for an outside service; each full page lists them under Before you install.

Do these video skills work with Codex and Cursor?

Yes. Each of the 15 video skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 3 of them declare compatibility in the SKILL.md frontmatter.

How does SuedeAI.directory rank video skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files. A skill joins this page when its name or summary matches the video keyword map; each repository fills at most three rows, so the table compares publishers.
