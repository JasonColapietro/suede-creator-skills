Questions and answers

Which iOS skill has the highest Suede Skill Check score?

expo-migrate-module from expo/skills scores 87/100, grade B, the highest of the 26 listed iOS skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. expo-module from expo/skills follows at 87/100.

How do I install an iOS skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For expo-migrate-module, run: npx skills add https://github.com/expo/skills/tree/main/plugins/expo-experiments/skills/expo-migrate-module. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these iOS skills free?

All 15 iOS skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (10) and Apache-2.0 (5), so you can use and adapt the files at no cost under those terms. 3 skills name credentials for an outside service; each full page lists them under Before you install.

Do these iOS skills work with Codex and Cursor?

Yes. Each of the 15 iOS skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 3 of them declare compatibility in the SKILL.md frontmatter.

How does SuedeAI.directory rank iOS skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files.
