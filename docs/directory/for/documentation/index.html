Questions and answers

Which documentation skill has the highest Suede Skill Check score?

go-documentation from eduardo-sl/go-agent-skills scores 95/100, grade A, the highest of the 32 listed documentation skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. diataxis-writer from tronghieu/agent-skills follows at 87/100.

How do I install a documentation skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For go-documentation, run: npx skills add https://github.com/eduardo-sl/go-agent-skills/tree/main/skills/(code-quality)/go-documentation. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these documentation skills free?

All 15 documentation skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (10), Apache-2.0 (4) and MPL-2.0 (1), so you can use and adapt the files at no cost under those terms.

Do these documentation skills work with Codex and Cursor?

Yes. Each of the 15 documentation skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 2 of them declare compatibility in the SKILL.md frontmatter.

How does SuedeAI.directory rank documentation skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files. A skill joins this page when its name or summary matches the technical documentation keyword map; each repository fills at most three rows, so the table compares publishers.

Which documentation skills come from official publishers?

provider-docs from HashiCorp, api-documentation from LambdaTest, docs-sync-audit from GitHub and doc-coauthoring from Sentry are published by the company behind the tool, marked Official in the table.
