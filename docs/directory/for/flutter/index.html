How do I install a Flutter skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For dart-build-cli-app, run: npx skills add https://github.com/flutter/skills/tree/main/skills/dart-build-cli-app. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these Flutter skills free?

All 7 Flutter skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by BSD-3-Clause (3), MIT (3) and Apache-2.0 (1), so you can use and adapt the files at no cost under those terms.

Do these Flutter skills work with Codex and Cursor?

Yes. Each of the 7 Flutter skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex.
