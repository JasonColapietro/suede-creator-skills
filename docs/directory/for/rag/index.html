Which RAG skill has the highest Suede Skill Check score?

google-cloud-solution-rag-enterprise-search-gke-sqldb from google/skills scores 87/100, grade B, the highest of the 55 listed RAG skills in the October 22, 2026 snapshot. How do I install a RAG skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For google-cloud-solution-rag-enterprise-search-gke-sqldb, run: npx skills add https://github.com/google/skills/tree/main/skills/cloud/google-cloud-solution-rag-enterprise-search-gke-sqldb. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these RAG skills free?

All 15 RAG skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by Apache-2.0 (9), MIT (5) and CC-BY-4.0 AND Apache-2.0 (1), so you can use and adapt the files at no cost under those terms. One skill names credentials for an outside service; each full page lists them under Before you install.

Do these RAG skills work with Codex and Cursor?

Yes. Each of the 15 RAG skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 3 of them declare compatibility in the SKILL.md frontmatter.
