How do I install a Terraform skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For agent-platform-alert-configuration, run: npx skills add https://github.com/google/skills/tree/main/skills/cloud/agent-platform-alert-configuration. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.
