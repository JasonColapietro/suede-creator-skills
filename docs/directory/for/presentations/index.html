Questions and answers

Which presentation skill has the highest Suede Skill Check score?

slidewright from tronghieu/agent-skills scores 90/100, grade A, the highest of the 20 listed presentation skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. pptx from anthropics/skills follows at 87/100.

How do I install a presentation skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For slidewright, run: npx skills add https://github.com/tronghieu/agent-skills/tree/main/skills/slidewright. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these presentation skills free?

All 15 presentation skills on this page are published in public GitHub repositories and cost nothing to download. 13 use an open-source or open-content license, led by MIT (10) and Apache-2.0 (3), so you can use and adapt the files at no cost under those terms. pptx and ppt-editing-skill are published under the publisher's own terms, which restrict copying; read them before you install. One skill names credentials for an outside service; each full page lists them under Before you install.

Do these presentation skills work with Codex and Cursor?

Yes. Each of the 15 presentation skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs 13 of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. pptx and ppt-editing-skill follow the publisher's own install route, shown on their page. 2 of them declare compatibility in the SKILL.md frontmatter.

How does SuedeAI.directory rank presentation skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files. A skill joins this page when its name or summary matches the presentations keyword map; each repository fills at most three rows, so the table compares publishers.

Which presentation skills come from official publishers?

pptx from Anthropic, presentation-creator from Sentry, publish-to-pages from GitHub and slide-making-skill, color-font-skill and ppt-editing-skill from MiniMax are published by the company behind the tool, marked Official in the table.
