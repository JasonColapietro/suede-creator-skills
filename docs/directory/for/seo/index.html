Which SEO skill has the highest Suede Skill Check score?

seo-dataforseo from AgriciDaniel/claude-seo scores 88/100, grade B, the highest of the 87 listed SEO skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and instruction depth. seo-image-gen from AgriciDaniel/claude-seo follows at 88/100.

How do I install an SEO skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For seo-dataforseo, run: npx skills add https://github.com/AgriciDaniel/claude-seo/tree/main/skills/seo-dataforseo. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these SEO skills free?

All 15 SEO skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (12), Apache-2.0 (2) and ISC (1), so you can use and adapt the files at no cost under those terms.

Do these SEO skills work with Codex and Cursor?

Yes. Each of the 15 SEO skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 4 of them declare compatibility in the SKILL.md frontmatter.
