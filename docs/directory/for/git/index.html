Questions and answers

Which Git skill has the highest Suede Skill Check score?

pr-improver from trailofbits/skills scores 93/100, grade A, the highest of the 45 listed Git skills in the October 22, 2026 snapshot. It earns full points for structural checks, recent maintenance and curated-list citations. git-commit from eduardo-sl/go-agent-skills follows at 92/100.

How do I install a Git skill in Claude Code?

Run npx skills add with the skill folder's GitHub URL from your project, or copy the folder into .claude/skills/ and Claude Code loads it when a request matches its description. For pr-improver, run: npx skills add https://github.com/trailofbits/skills/tree/main/plugins/code-improver/skills/pr-improver. Each full skill page on SuedeAI.directory lists the same steps for Claude Code and Codex.

Are these Git skills free?

All 15 Git skills on this page are published in public GitHub repositories and cost nothing to download. Every one uses an open-source or open-content license, led by MIT (9), Apache-2.0 (4) and CC-BY-SA-4.0 (2), so you can use and adapt the files at no cost under those terms. One skill names credentials for an outside service; each full page lists them under Before you install.

Do these Git skills work with Codex and Cursor?

Yes. Each of the 15 Git skills on this page is a SKILL.md folder in the Agent Skills format, which Claude Code, Codex and Cursor all read. The skills CLI (npx skills add) installs every one of them into Claude Code, Codex, Cursor and other agents, and each full skill page adds a project-level copy into .claude/skills for Claude Code and .agents/skills for Codex. 4 of them declare compatibility in the SKILL.md frontmatter.

How does SuedeAI.directory rank Git skills?

By Suede Skill Check score from 0 to 99, which adds structure, description quality, instruction depth, bundled files, maintenance and curated-list citations, all read from each skill's published files. A skill joins this page when its name or summary matches the Git and pull requests keyword map; each repository fills at most three rows, so the table compares publishers.
