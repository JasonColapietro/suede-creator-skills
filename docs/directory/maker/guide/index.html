From featured to finished.

Give people the right starting point for your project. No real GitHub sign-in is part of this demo.

Set up your maker profile

  1. Open your featured listing. Read the live page as a visitor would. Check its name, scope and current links.
  2. Sign in with GitHub and request access. Use the account that controls the project. Access is verified for the specific listing. For an organization project, review may be needed.
  3. Fill out your profile. Add a statement, official website, demo, social profiles or up to three selected post links. Posts are links, not embedded feeds. The fields start blank. Only enter information you want publicly displayed after approval.
  4. Preview and submit. Check spelling and open the links from your own browser. Review keeps the existing listing public until the details are approved.
  5. Ask Suede. Read the existing editorial review in the listing panel. After claiming, send a private re-review request or ask for improvement feedback. Return here to read the reply. A request does not change a grade.
  6. Share once it’s live. Use the published listing URL and the project’s Featured badge. A star or backlink is not required to claim or update a profile.

MAKER CHECKLIST

Have these ready.

  • The GitHub account connected to the project.
  • An official website with an HTTPS address.
  • Public project social profile links, if you want to share them.
  • Up to 320 characters on what you built and who should use it.

Grades, rankings and editorial copy are managed separately. If something in Suede’s write-up needs correcting, flag it for review rather than putting it in your maker statement.
