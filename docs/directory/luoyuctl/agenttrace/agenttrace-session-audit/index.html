How the author describes it

Audit local AI coding-agent sessions with agenttrace. Use when the user asks to inspect Claude Code, Codex CLI, Qwen Code, Cline, Aider, Cursor exports, Hermes Agent, OpenCode, OpenClaw, Pi, Oh My Pi, Kimi CLI, Copilot-style logs, or generic JSON/JSONL traces for cost, tokens, tool failures, latency, anomalies, health, diffs, or CI gates.

Install agenttrace-session-audit

Skills CLI (Claude Code, Codex, Cursor and other agents):

npx skills add https://github.com/luoyuctl/agenttrace --skill agenttrace-session-audit

Claude Code, project-level copy:

git clone --depth 1 https://github.com/luoyuctl/agenttrace.git /tmp/agenttrace
mkdir -p .claude/skills
cp -R /tmp/agenttrace/skills/agenttrace-session-audit .claude/skills/

Codex installer:

python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
    --repo luoyuctl/agenttrace \
    --path skills/agenttrace-session-audit
