How to choose AI agent and LLM engineering skills

Start from the system you are building. Skills for a specific framework or model provider carry that provider's conventions, so they beat general prompting advice when you already know your stack.

Check what a skill expects to run. Training and inference skills often name GPU tooling, cloud credentials or a model hub token; the Before you install panel on each page lists the scripts it bundles and the environment variables its code reads.

For agent workflow skills (planning, subagents, review loops), read the SKILL.md body first. They change how your agent works on every task, so pick one method and stay with it rather than stacking overlapping ones.
