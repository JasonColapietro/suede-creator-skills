Version 0.14.0 released Aug 16, 2026

282 commits · 10 weeks · newest on the right

  1. 2026-08-16 MCP 1e2d70e

    Six specialities, and an MCP that navigates them

    Version 0.14.0 splits the lopsided specialty and gives the MCP a way through the whole pack. The five-way cut shipped hours earlier left Convert & earn at 23 while every other bucket sat between 9 and 15, so it splits on its real seam: Demand channels 8 and Revenue & retention 15, alongside Ship 15, Craft 9, Get found 12, and Strategy & rights 14. Largest bucket 23 to 15. The MCP could previously only be pointed at the three bundle areas; it now ships list_suede_specialties and a suede://specialties resource so a client picks a group before asking for skills, accepts --profile for any one specialty, and advertises only the specialities a given profile can serve. Closes a real hole on the way: amazon-returns-recovery and subscription-recovery sat in the catalog and on the site behind no registered server, unreachable by any MCP client, because consumer was a valid profile that .mcp.json never registered.

  2. 2026-08-16 Rework 67c4c7f

    The pack gets five specialities

    Version 0.13.0 re-cuts how the pack is browsed. The 73 skills were grouped four ways by area — marketing 41, workflow 25, creator 5, consumer 2 — and separately eight ways on the catalog page, with two more inconsistent cuts on the homepage. Marketing was a 41-name wall in every one of them. There are now five specialities, each with named sub-lanes: Ship 15, Craft 9, Get found 12, Convert & earn 23, Strategy & rights 14. The largest bucket goes 41 to 23. area is deliberately unchanged — it still decides which plugin bundle and MCP profile ships a skill, so nothing moved between install surfaces. list_suede_skills and search_suede_skills take a specialty filter, and the per-specialty counts on all three site surfaces are generated guards, not hand-typed numbers.

  3. 2026-08-16 Site 687d7b9

    The last page still carrying its own navigation markup moves onto the shared no-JS-safe <details> disclosure, and a drift guard now covers all 101 pages, so a page added later cannot ship a nav that behaves differently from the rest of the estate.

  4. 2026-08-16 Perf 51bcfd0

Full Send

Enthusiasm in. Proof out.

Tell most agents "max effort, fix everything" and you get vibes. /suede-full-send turns that intent into a structure: one authorized controller, every useful non-colliding lane in parallel, adversarial reconciliation where lanes attack each other's claims, and a close that is either concise proof or one named blocker.

House line: "Never end your allocation above zero." Dry joke, not a literal token promise. The full DAG behind it ships as /suede-ship, and the copy-only variant as /suede-ship-copy.

What your agent learns.

01 Suede Fable Fleet — Codex worker fleets

Claude judges.
Codex generates.

Claude decomposes a high-volume job, writes self-contained briefs, spawns parallel OpenAI Codex CLI workers billed to your ChatGPT plan, then reviews every output against acceptance criteria before anything ships.

02 Code review → ship verdict

Review that ends in
a blunt A-F grade.

Deep findings across TypeScript, React, Next.js, Swift/iOS, OWASP, and database checklists, then a letter verdict across 7 evidence-backed lanes. A hardcoded secret is an instant F with the exact file and line — no other lane can raise it. iOS gets its own traps list: force unwraps, main-thread violations, and native contract drift that crashes shipped apps.

03 Skills, not prompts

Every capability is an inspectable SKILL.md folder the agent loads on demand, so context stays lean and the job stays in focus

04 Agent teams

Runs scout, build, review, verifier, and release lanes that share context instead of acting like siloed subagents — with WIP collision detection and a signed handoff

05 AI evals

Turns LLM, RAG, classifier, and agent surfaces into measurable AI-SPECs with failure-mode rubrics, eval cases, and acceptance gates you can fail a release on

06 CI ship gate

Writes CI that actually gates the merge: stack and lockfile detection, one required check that can't deadlock, and branch protection that holds

07 Suedify

Point it at any URL. It reverse-engineers the layout logic, type rhythm, and color strategy that make that site work, then rebuilds your page in that language — your own copy, your own assets, nothing traced or copied

08 Conversion copy

Runs the same persuasion frameworks agencies bill five figures to teach — AIDA, PAS, StoryBrand, JTBD — plus 12 headline formulas and a 29-point anti-slop gate before a word ships

09 SEO, AEO & AI EO

Nine audit lanes in one pass — technical, intent, metadata, structure, schema, AI citation readiness, copy quality, E-E-A-T, topic clusters — wider than any single-purpose SEO skill in the wild

10 Visibility grade

Scores brand and page visibility A-F across first-screen clarity, CTA pull, proof, AI readability, schema depth, and search result fit

11 Site to iOS app

Takes a live URL through the App Store 4.2 wrapper-risk gate, a native or Capacitor shell, and screenshots polished enough for a downtown agency pitch deck, not a template generator

12 Design, from first principles

Commits to a named aesthetic lane, rejects the first reflex and the second-order trap, and builds color, type, and motion up from that decision — never a template with your logo dropped in

13 Consumer recovery

The same negotiation discipline pointed at your own accounts: one skill argued Amazon into refunding $448.31, the other audits Netflix, gyms, and every App Store subscription you forgot you had

14 Taste memory

Say "Cue Suede" mid-run and choose: change something, preserve what worked, or accept as-is. The skill mimics what worked on every pass after — across design, copy, agent-team, and launch-packaging lanes

15 Android app factory

One prompt to a Play Store-ready native app: Kotlin + Jetpack Compose scaffolding, Play Billing, ASO listing copy sized to Play's character limits, and a signed release gated the same way as everything else in this pack

The router

Don't memorize a command list.

Ask in plain words. The umbrella skill, /suede-workflow-skills, reads the request and loads the right lane — one install, every skill reachable. Agents that speak MCP get the same routing as structured tools: list_suede_skills finds the skill, get_suede_skill loads it.

The optional MCP server ships in the repo, runs local with zero dependencies, and adds install options, audit scaffolds, grading, and QA checklists on top of discovery. Wire-up lives on the install page.

Questions, answered.

What are Agent Skills?

Agent Skills are SKILL.md folders that Claude Code and OpenAI Codex load on demand to follow a documented workflow. This pack ships them under the MIT license: outcome-bound orchestration, code review and grading for web stacks and Swift/iOS, a site-to-iOS app conversion workflow, a one-prompt Android app factory, CI ship-gates, AI evals, Instagram growth, design, copy, SEO, marketing and growth, and a creator toolkit for music rights and release prep. Every folder is plain Markdown you can read before you install it.

How do I install the pack?

In Claude Code, run /plugin marketplace add JasonColapietro/suede-creator-skills, then /plugin install suede-skills@suede. In Codex, run codex plugin marketplace add JasonColapietro/suede-creator-skills --ref main, then codex plugin add suede-skills@suede-codex. The direct Codex skill installer remains available for one selected skill. Full paths live on the install page.

Does it work with both Claude Code and Codex?

Yes. Each skill is a standard SKILL.md folder. Claude Code and Codex both install the full pack through their native plugin marketplaces; direct folder and single-skill installs remain available.

Is it safe to run?

The skills inspect local files and pages and write local reports. They do not upload files by default, write to any registry, request secrets, or claim legal clearance. The whole pack is MIT licensed and inspectable before you enable anything.
