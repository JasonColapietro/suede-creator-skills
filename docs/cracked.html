Instant release. No downtime, no intervals.

The IR formulation runs the whole stack as one continuous subagent-driven pass: a single controller fans out every useful non-colliding lane at once, keeps every worker hot until the finish line, turns adversarial review on its own output mid-run, and lands with evidence. You paste one prompt. It comes back shipped.

adderall-ir · one dose 
/suede-ship <your outcome> — instant release: run this as one
continuous subagent-driven pass. Fan out every useful non-colliding
lane at once and keep every worker busy until the finish. No pauses,
no check-ins, no intervals. Adversarial review inside the run.
Evidence at the end.
What fans out

The controller reads the outcome, cuts it into non-colliding lanes, and hands each lane to a subagent with its own brief. Research, build, review, and verification all run in parallel instead of taking turns.

What never happens

Idle time between phases. A status update instead of progress. The run pausing to ask whether it should keep going. The plan and the work happening in separate sessions.

What comes back

A finished change with an adversarial review trail and evidence a gate can check — not a summary of what an agent would do if you asked again nicely.

IR is the expensive formulation on purpose. suede-ship says it on its own label: light, standard, and deep searches stop at 55, 110, and 200 total agent calls. It searches competing plans and lets only the selected winner mutate.

Extended release XR · for the long session

When the run lands, suede-recommend-next-action has already scored the next move on goal fit, unblocking, evidence, urgency, and leverage — and hands it back as a short runnable prompt. The session never idles between doses of work.

The whole formulary. Each one is a plain-Markdown folder you can read on GitHub before you enable it; together they turn one polite assistant into a shipping organism.

Generate competing plans, score and prune, refute and improve, aggregate compatible lanes, then mutate only the selected plan. 55/110/200-call caps; production reads only, never deploys. suede-agent-teamsThe org chart. Coordinates complex changes across agent lanes with collision detection, quality gates, and a signed handoff. suede-workflow-skillsThe umbrella. One install that routes an agent across every lane in the pack, so the right specialist loads without you naming it. suede-recommend-next-actionThe momentum loop. Scores candidate moves on goal fit, unblocking, evidence, urgency, and leverage, then hands back one move as a short runnable prompt.
