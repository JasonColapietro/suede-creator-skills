/suede-influencer-outreach · Marketing & growth

Influencer Outreach skill Creator pitches built on a post you can name and an offer with a number.

It pitches one creator at a time, the way a partnerships manager would: an opener grounded in a post you can name, the real compensation stated by model, one ask, and the contact the creator actually publishes, manager included. A two-follow-up plan closes the file cleanly, and the package hands the agreed facts straight to negotiation.

View skill folder Install options

When to reach for it

The user is pitching an influencer, creator, newsletter writer, or podcaster for a sponsorship or collab, or their creator outreach gets no replies.

Example prompt

codex / claude code
Use $suede-influencer-outreach on [creator]. The user is pitching one vetted creator, newsletter writer, or podcaster, or their creator outreach gets no replies. Ground the opener in a named post or audience fact, state the real compensation by model, fit the message to the contact the creator publishes, keep to one ask, and return the pitch package with a bounded follow-up plan.
