/suede-reverse-engineer-anyone · Marketing & growth

Suede AI Reverse Engineer Anyone Skills Every number traces to a dated file in the teardown folder.

It rebuilds a target's growth as a dated history: one growth curve from one source, a log of every move, the funnel and content patterns behind it, and the hidden signals most teardowns skip. Code finds the inflections and the move clusters around them, the user's own numbers set the gap, and each play arrives routed to the Suede skill that runs it, with a paste-ready prompt.

Example prompt

codex / claude code
Use $suede-reverse-engineer-anyone on [target]. The user wants to know how a company, creator, artist, founder brand, app, or launch grew and what to copy. Build a one-source growth curve and a dated move log from public evidence, find what moved the curve with the timeline script, compare it with the user's own numbers, and return ranked plays, each routed to the Suede skill that runs it with a paste-ready prompt.
