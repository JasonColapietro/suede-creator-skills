/suede-ops-assessment · Operations mapping

Map the floor, not the org chart.

Suede Ops Assessment interviews the people who do the work rather than the people who describe it, inventories every silo including the spreadsheets and inboxes nobody lists as software, attaches a number to each bottleneck using the operation’s own figures, and ranks the opportunities by annual value against build complexity — including the ones that look impressive and return little.

View skill folder Install options

When to reach for it

The user cannot say what to automate, wants their operation mapped and costed before a build, needs tribal-knowledge and key-person risk surfaced, or has a shipped system the team is quietly routing around.

Example prompt

codex / claude code
Use $suede-ops-assessment on [target]. The user cannot say what to automate, or wants their operation mapped before anything gets built. Interview the people who do the work rather than only those who manage it, inventory every silo including spreadsheets and inboxes used as databases, quantify each bottleneck in the user's own numbers without substituting benchmarks, rank the opportunities by annual value against build complexity, and return the floor map, the ranked list, and what is still missing.
