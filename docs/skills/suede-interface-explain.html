Suede AI Interface Explain Skills Understand what makes the interface work.

Bring an interface question: why a header sticks, how a panel opens, where a filter gets its state, or what controls a responsive layout. The skill traces the existing implementation and explains the causal path with source locations. Browser observations and inferred behavior are labeled separately, and application files stay unchanged.

Read the skill Install options

"Explain this interface and trace the mechanism in the source." -> /suede-interface-explain The workflow router selects this task when the skill is available.

Follow the mechanism

  • Locate the source entry points and dependencies relevant to the user's question.
  • Trace inputs, event handlers, state transitions, layout rules and rendered output.
  • Cite concrete file locations for mechanism claims.
  • Explain the causal sequence in plain language, using a diagram when it makes that sequence easier to follow.

Know what the evidence shows

  • Source facts describe what the inspected code declares.
  • Rendered observations describe behavior actually seen in the available interface.
  • Inferences identify conclusions that still depend on runtime, data or environment assumptions.
  • Unobserved states stay explicit; source inspection does not earn a rendered visual pass.

Read-only by default

The explanation preserves the existing interface. It does not refactor, rebuild, add a demonstration route or perform live transactions. If source access is unavailable, it can explain observed behavior while identifying the mechanism details that remain uncertain.

The output follows the question's scope. A design review, workbench or implementation is a separate task with its own entry point.

Example request

Use $suede-interface-explain to explain how this filter panel opens, updates the URL and restores its state. Trace the relevant files, event handlers, state and rendering. Keep application files unchanged. Separate source facts, observed browser behavior and inference, and say which parts you could not observe.
