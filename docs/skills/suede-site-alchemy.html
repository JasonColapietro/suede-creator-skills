/suede-site-alchemy · Conversion architecture

Find where the funnel bleeds.

It ranks every fix by evidence strength, affected traffic, and effort, and where the impact is not known yet it names the measurement that will settle it instead of inventing a lift. Friction gets inventoried three ways, cognitive, physical, and trust, each item with its evidence, affected population, and severity, across the hero, the proof, the CTA, the pricing, and the mobile path. The copy itself is suede-copy; the SEO score is suede-seo-audit.

What it covers

  • Funnel analysis that names TOFU, MOFU, or BOFU before optimizing the page.
  • Friction audits across cognitive load, physical effort, trust gaps, and mobile CRO rules.
  • Conversion math using visitors, CTR, conversion rate, and order value before ranking hypotheses.
  • Page contracts for buyer action, offer spine, proof stack, CTA ladder, route targets, and claim limits.
  • Slash-tool passes for vibe scan, hero voltage, offer spine, proof stack, CTA magnet, mobile polish, and ship polish.
  • Ship checks for local preview, desktop and mobile QA, text fit, CTA and link sweep, diff check, and live verification when public.

When to use it

  • Make a page convert better, fix a landing page or campaign page that is not converting, or sharpen a hero and CTA.
  • Run a CRO or friction pass on campaign landing pages, launch pages, link-in-bio pages, creator profiles, or product microsites.
  • Build a conversion-focused microsite or upgrade a static site with SEO, AEO, or AI EO page work.
  • Handle Suede Sites positioning, cross-sells, CTAs, and module menus when the current source supports the route.
  • Not for: an A-F promotion-readiness grade (use suede-visibility-grader).
  • Not for: a nine-lane SEO/schema audit (use suede-seo-audit).
  • Not for: standalone copywriting (use suede-copy).

Best prompt

Use $suede-site-alchemy to audit this campaign landing page, name the funnel stage, score cognitive, physical, and trust friction, run conversion math from our traffic and order value, sharpen the hero and CTA ladder, and return ranked quick wins plus desktop and mobile QA checks.
