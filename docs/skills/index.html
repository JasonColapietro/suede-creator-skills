Skill catalog

Every skill. One honest line each.

Every skill in the pack is a plain-Markdown SKILL.md folder you can read before an agent runs it. Six specialities: ship (13), craft (9), get found (12), demand channels (8), revenue & retention (15), and strategy & rights (14). Each one breaks down further into sub-lanes, so no bucket is a wall of names. This catalog links each skill to its deep docs and its source folder on GitHub. No sign-up, no telemetry, nothing to uninstall but a folder.

Full history on GitHub ->

  1. 2026-08-15 Rework 1163506

    The entire skill pack gets its first major redesign

    Version 0.12.0 gives all 73 skills clearer routing, 1,149 fewer hot-path instruction lines, progressive-disclosure references, and bounded orchestration. The portable SKILL.md format gives Grok and other skills-compatible agents a leaner signal without changing Claude Code, Codex, or MCP installs.

  2. 2026-08-10 MCP a49a998

    Skill search stops needing your exact wording

    A shared four-character stem now counts toward a match in search_suede_skills, and a stopword list replaces the length floor that dropped ai and qa. A 15-case routing eval runs in CI.

  3. 2026-08-09 MCP 15de94d

    41 skills come out from behind the MCP

    Version 0.11.0 gives the marketing and consumer lanes a profile that can reach them. Adds a suede_marketing_mcp registration, a search_suede_skills tool that ranks skills against a task description, and includeBody on get_suede_skill.

  4. 2026-08-04 New skill

    The shipping DAG gets a copy twin

    suede-ship-copy runs the same graph over a piece of writing: five blind research lenses, an audit that opens every agent-generated claim against its source, three independent angles, one message per section, adversarial review, and a deslop pass. Facts you supply yourself are given and never audited. The pack moves 69 -> 70.

  5. 2026-08-04 New skill a086a81

    Instagram growth gets an evidence system

    Version 0.10.0 adds suede-instagram-growth: authorized account audits, attention-versus-conversion mapping, Reels, carousels, Stories, experiment cards, and an approval-gated daily loop. The pack moves 68 -> 70 and the marketing lane moves 38 -> 39.

  6. 2026-08-04 Route fix 831214b

    Shipping and CI stop sharing one name

    suede-ci-gate now unambiguously owns CI and branch protection, while suede-ship owns the full shipping DAG. Public catalog, install, routing, documentation, and sitemap references match.

  7. 2026-08-03 New skill e51c635

    The canonical shipping DAG joins the pack

    suede-ship adds scout, multi-lens research, gap criticism, collision-free lanes, parallel build, dual review, adversarial refutation, integration gates, and release verification. The pack moves 67 -> 68.

  8. 2026-08-01 Fix 67a2b51

    Reserved MCP metadata no longer breaks startup

    Version 0.9.2 accepts the protocol-reserved _meta object sent by current Codex clients while continuing to reject unrelated parameters. Both Suede MCP profiles now complete discovery.

  9. 2026-08-01 Site f7cd12e

    The thirty-eight marketing skills stop being invisible

    The marketing and growth lane opened inside the gold install band instead of the catalog, rendering gold on gold at a contrast ratio of 1.0. The same thirty-eight were missing from llms.txt and their plugin was advertised nowhere. Counts on this page still read 28. Every fix ships with a validator guard.

  10. 2026-08-01 Site 8e30eca

    Seventy-two pages become keyboard passable

    All 68 skill pages plus the catalog, install, copy bank and both blog pages now ship a skip link targeting a focusable <main>, per WCAG 2.4.1. Four homepage labels also stopped using the fill-only red as text, clearing 4.5:1 against every composited background.

  11. 2026-07-28 Rework 189ae51

    The marketing stack becomes Suede-native

    Version 0.9.1 rewrites thirty-eight marketing and growth skills around Suede contracts, evidence and authority boundaries, interruption-safe state, deterministic routing, and aligned metadata, evals, references, and docs.

  12. 2026-07-27 New skill f0c3751
