The ship verdict

Suede Code + Grader + Ship Gate

suede-code reviews a staged diff against framework and OWASP checklists, then scores it A to F across 7 lanes, from correctness to deploy readiness. The weakest lane caps the grade, so six A lanes and one F lane is an F. A hardcoded secret, or an auth check a request param can walk around, locks it at F with the file and the line. The ship gate blocks the merge.

Johnny Suede Write + Design

One name loads the whole writing or design stack. Copy leaves through a 50-point anti-slop gate that catches filler, manufactured emphasis, and formulaic contrast. Pages leave through an A to F visibility grade. Both hand back a score before anything publishes.

A read-through of the 74 skills repaired 19 defects, among them two truncated Codex descriptions, two stale Suede Ship Gate names, a dead slash-tool reference, an advisory-gate contradiction, two NOT FOR clauses the validator could not see, and nine catalog descriptions resynced to their skills.   4. 2026-08-21 Orchestration d8a6ae8

    Version 0.15.0 replaces suede-graph-flo-xr's fixed single-plan DAG with a bounded Graph-of-Thoughts search. It generates competing plans, scores and prunes them, adversarially refutes and improves survivors, aggregates compatible lanes, then builds, reviews, and gates only the selected plan. Light, standard, and deep stop at 55, 110, and 200 total agent calls. Production access remains read-only; the skill never deploys.

  5. 2026-08-16 MCP 1e2d70e

    Six specialities, and an MCP that navigates them

    Version 0.14.0 splits the lopsided specialty and gives the MCP a way through the whole pack. The five-way cut shipped hours earlier left Convert & earn at 23 while every other bucket sat between 9 and 15, so it splits on its real seam: Demand channels 8 and Revenue & retention 15, alongside Ship 15, Craft 9, Get found 12, and Strategy & rights 14. Largest bucket 23 to 15. The MCP could previously only be pointed at the three bundle areas; it now ships list_suede_specialties and a suede://specialties resource so a client picks a group before asking for skills, accepts --profile for any one specialty, and advertises only the specialities a given profile can serve. Closes a real hole on the way: amazon-returns-recovery and subscription-recovery sat in the catalog and on the site behind no registered server, unreachable by any MCP client. consumer was a valid profile that .mcp.json did not register.
