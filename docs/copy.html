Code grade and agent-team copy

Use suede-code when a diff needs more than a polite review. It grades a staged diff A-F across seven lanes, from correctness and security through tests and deploy readiness, and the weakest lane caps the grade. A hardcoded secret, or an auth check you can walk around with a request param, locks it at F with the file and the line, and no other lane lifts it. Use suede-ci-gate when the verdict has to block the merge.

Agent-team loop copy

Split major work into lanes that own separate files and report to one controller. WIP collision detection keeps two lanes off the same file, rollback trees keep a bad lane from taking the branch with it, and the handoff checklist will not close without evidence.

Ship DAG copy

Use Suede Graph Flo XR when the outcome is broad, authorized, and worth maximum useful effort. It writes competing plans for the change, scores them, prunes, refutes the survivors, and builds only the winner. Light, standard, and deep cap the run at 55, 110, and 200 calls. It reads production for evidence and never deploys, and it does not expand permissions, spend authority, or model limits.

cracked stack post · technical 
I added a curated stack to Suede Creator Skills and made the marketing do engineering work.

Cost is on the label. The Suede Thought Graph search caps light, standard, and deep at 55, 110, and 200 calls, only the selected winner mutates, and production inspection is read-only.

The Agentic Adderall Stack groups the pack's four orchestration skills (ship, agent-teams, workflow-skills, recommend-next-action). Instant release is one continuous subagent-driven pass: the controller fans every disjoint lane out at once, adversarial review runs inside the pass, and the close is an evidence gate. Extended release is the scheduling counterpart: a scorer ranks the next move on goal fit, unblocking, evidence, urgency, and leverage, then emits it as a runnable prompt.

The grouping is a cross-cutting overlay in the catalog, not a seventh category. The specialty partition stays total, the validator fails CI if the stack's page and its catalog membership drift, and the MCP server scopes the stack per profile.

It runs offline. These are the limits, in plain words.

  • Public v1 runs offline and writes local files. It ships no binaries and no telemetry.
  • Generated reports are drafts until a creator or operator reviews them.
  • These skills organize evidence. They do not provide legal clearance.
  • The scripts skip hidden files, dependency folders, build outputs, caches, and secret-like files by default.
  • Unknown rights facts stay marked as unknown.
