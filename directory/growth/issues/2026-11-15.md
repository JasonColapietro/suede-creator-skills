# Suede Rising Skills

*Week of November 15, 2026 · for builders using AI to make money*

**New here?** Suede Rising Skills tracks the AI agent skills builders install and star each week. A skill is an add-on that teaches an AI coding agent such as Claude Code, Codex or Cursor a new job. Every skill in the [Suede Skills Directory](https://suedeai.directory/) gets a Suede Skill Check score from 0 to 99, based on how well it is built: structure, documentation, examples and upkeep. A is 90 or higher, B is 80+, C is 70+ and D is below 70, so "88 B" means a score of 88, grade B. **Installs** are how many times builders installed a skill with the skills install command.

## 💼 8 AI businesses in two models, ranked by score: start with #1

We scored each idea on four questions, 1–5 each, and ranked them by score within each business model:

- **Demand:** is this week's install growth rising for this kind of work?
- **Tools:** are B-grade or better skills and a ready-made workflow available?
- **Autonomy:** can it run without you?
- **Buyers:** do businesses already pay people to do this job?

*These are our editorial scores from this week's data, not revenue forecasts.*

**Two ways to run them.** *Autonomous* ideas run on [Suede Agent Studio](https://agents.suedeai.ai/), an agent builder where you set up an agent that does one job and charges your customers per job. *You sell it* ideas are services you sell yourself, with agents doing the heavy lifting. A **template** is a ready-made Agent Studio workflow you open and adapt.

### Autonomous: the agent does the work and charges per job

These start from Agent Studio's [self-running companies](https://agents.suedeai.ai/company), where each "employee" agent has a job and a price it charges per call. Every price below is the template's default charge, and you set your own.

- **[alexeyw/lot-map](https://github.com/alexeyw/lot-map)** · 840 ⭐: A live map beside the chat that lights up every tool call, hook, skill and subagent as Claude Code works. Local only, 7 languages. **Money angle:** show clients exactly what their agent did when you bill for agent work.
- **[JDhruv14/line-art-animation](https://github.com/JDhruv14/line-art-animation)** · 778 ⭐: A Claude skill that draws animated line-art: ink figures that walk and react, scenes with a day/night cycle. **Money angle:** sell animated hero sections and explainer scenes to landing-page clients.
