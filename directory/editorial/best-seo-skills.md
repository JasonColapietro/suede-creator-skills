## How were these skills chosen?

Each pick is listed in the directory, sits in the Marketing and SEO category or does SEO work, and is the strongest scorer for its job. The score is the directory's [graded-v2 quality score](https://skills.suedeai.ai/directory/methodology/). It adds points for passing the structural checks, a clear trigger description, a stated boundary, instruction depth, bundled references and scripts, recent commits, citations from curated lists, and declared tool permissions. Published scores run from 0 to 99.

The score measures structural evidence in the skill's files. It does not measure how well the skill ranks your pages. Read each SKILL.md before you install it, and check what it sends to outside services: `seo-dataforseo` and `seo-google`, for example, call external APIs with your credentials.

## Which skill should you use for a technical SEO audit?

Use `seo-audit` from coreyhaines31/marketingskills when you want an agent to diagnose why a site is not ranking. It scored 88/100 and its repository is cited by four curated lists in the snapshot, the maximum adoption credit. If you also want the audit to report on AI search performance, `seo` from mblode/agent-skills (87/100) covers technical fixes, demand research, content briefs and SEO, AEO and GEO measurement in one skill.

For a whole-site crawl, AgriciDaniel/claude-seo splits the work into many focused skills. Its umbrella `seo` skill (81/100) covers full audits, single pages, technical checks, schema, images, sitemaps and AI search. It works as a hub: when you already know the job, use the narrower skill from the same repository.

## Which skills help you show up in AI Overviews, ChatGPT and Perplexity?

Three listed skills target AI answers directly: `ai-seo` (coreyhaines31/marketingskills), `seo-geo` (infrasity-labs/dev-gtm-claude-skills) and `seo-content` (AgriciDaniel/claude-seo), which grades AI citation readiness. `agent-ready` from mblode/agent-skills (91/100) works on the machine side: llms.txt coverage and docs that agents can read without hitting 404s.

Keep Google's own guidance in view while you use them. Google Search Central says there are no additional requirements to appear in AI Overviews or AI Mode. A page needs to be indexed and eligible to show in Search with a snippet, and no special schema.org markup is required. Traffic from those features is counted in the Search Console Performance report under the Web search type. ([Google Search Central: AI features and your website](https://developers.google.com/search/docs/appearance/ai-features))

So the work that moves AI visibility is ordinary SEO done well, plus pages written so a model can lift a clean answer: a direct answer at the top, question headings, specific facts with sources, and a consistent name for your company and product everywhere it appears.

## Which skills handle schema markup?

`schema` from coreyhaines31/marketingskills scored 90/100, the top schema skill in the directory. `seo-schema` from AgriciDaniel/claude-seo (81/100) detects, validates and generates Schema.org JSON-LD for a page or entity. Whichever you use, Google's rule holds: structured data has to match the visible text on the page.

## Which skills cover keyword research and content briefs?

`keyword-deep-dive` from inhouseseo/superseo-skills (81/100) reads the top results and competitor pages for one keyword and returns a 90-day ranking plan. `seo-content-brief` from AgriciDaniel/claude-seo (86/100) turns competitor pages into a brief with section-level word counts. For live search volume, difficulty and SERP data, `seo-dataforseo` (88/100) connects to DataForSEO, which needs your own DataForSEO account.

## What about local, international and programmatic SEO?

- **Local:** `seo-maps` (85/100) covers geo-grid rank tracking, Google Business Profile audits and review analysis.

- **Programmatic:** `programmatic-seo` (88/100) plans template-driven pages built from data. Pair it with an index-worthiness gate so thin pages never ship.

## FAQ

### What is an SEO skill for Claude Code?

An SEO skill is a folder with a SKILL.md file that teaches Claude Code, Codex or another agent how to do one SEO job, such as an audit or a schema fix. The agent reads the skill's description to decide when to load it, then follows the instructions and any bundled scripts.

### Are these SEO skills free?

All of the skills in the table are published under open licenses (MIT or Apache-2.0). Some call paid services: `seo-dataforseo` needs a DataForSEO account, and `seo-google` uses your Google API access.

### Which SEO skill scores highest in the directory?

`site-architecture` from coreyhaines31/marketingskills, at 92/100, in the October 19, 2026 snapshot.

### Do I need special schema markup to appear in Google AI Overviews?

No. Google says no special schema.org markup is needed and there are no extra requirements beyond being indexed and eligible for a snippet. Structured data still helps search engines understand a page when it matches the visible text.

### How often are these scores updated?

The directory re-reads every source repository on each refresh and recomputes scores from the saved evidence. This guide is reviewed after each refresh.
