## Setup and data use

The current README requires Node.js 22.20+ for installation and describes current Node 22, 24 or 26 for the runtime. Rendering additionally needs FFmpeg/FFprobe and Playwright with Chromium; Three.js is used for the 3D starter. The code-only first example requires no paid generation or private media. Explicit package/browser setup downloads dependencies; the skill helpers are not an automatic installer.

The workflow works on local project files and produces a local review MP4. The inspected local server binds to loopback, and capture code includes browser network restrictions. These source observations are not an executed security test. AI artwork or narration through a separately chosen provider may transmit prompts/assets and incur charges. Rights, costs and publication remain separate user decisions. The submission's older Node 18+ wording is superseded here by the pinned README's 22.20+ setup.

The publisher's `docs/tested-setup.md` records a Fedora Linux/Chromium setup and example renders. Those are publisher-reported results, not tests repeated by the directory. No Windows/macOS or every-agent compatibility claim is made.
