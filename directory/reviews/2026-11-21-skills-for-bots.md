# Skills for Bots: accepted scope

Application [#430](https://github.com/JasonColapietro/suede-creator-skills/issues/430) · Decision: November 21, 2026.

**Accepted for the next regular catalog refresh, subject to the existing checks. No grade or publication date assigned.**

The starter supplies written approval rules for outbound messages and spending, plus a template for handing work between bots. The reminder skill describes one daily reminder until completion; delivery requires a host that can schedule it. Both are instructions, not enforced controls or a scheduling service. No other or paid edition is covered.
