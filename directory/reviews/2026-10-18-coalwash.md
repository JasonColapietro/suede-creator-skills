## Installation behavior and source review

Read the README, LICENSE, marketplace/plugin manifests, shipped SKILL.md,
`plugin/hooks/hooks.json`, conductor event handlers, write-guard code,
fidelity-gate interfaces, transaction/rollback code, and update instructions.
The source was downloaded as a pinned archive and read as data. No publisher
code, hooks, commands or installer ran, and no agent memory was modified.

The plugin installs executable Node.js code. SessionStart and Stop hooks run
the conductor; PreToolUse matches Edit/Write/MultiEdit; PostToolUse also observes
Agent/Task/Workflow activity. Session bookkeeping and snapshots write local
plugin state. Default automatic mode can direct mechanical Quick maintenance
without a fresh prompt. The Stop handler can emit blocking feedback to continue
maintenance. Full semantic work requires consent and uses the agent's model.

The write guard snapshots supported edits to memory/governance files, then
reports tracked-token drops. Shell-mediated writes are outside those edit hooks.
The structured-token gate compares tracked tokens rather than prose meaning;
token preservation cannot establish semantic preservation. Snapshots and rollback
provide recovery tools, but users must inspect diffs and recovery results.

The update hook schedules checks; agent-driven update instructions consult
GitHub and offer the plugin update. The feature makes no blanket offline,
network-free, lossless, malware-free or security-certification claim.
