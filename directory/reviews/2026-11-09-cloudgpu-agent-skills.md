## Setup and data use

Discovery compares current capacity and quotes without starting paid compute. Paid use requires a CloudGPU account connection, a user-approved workload/data destination, explicit spend and time caps, separately reviewed model and dependency revisions, and an export plan. Connecting an account is not job approval. The instructions prohibit automatic top-ups and reconcile uncertain resource creation before retrying.

Protect private inputs and model-serving endpoints: public instance tunnels are unauthenticated by default. Export and verify outputs before destroying an instance or exhausting its balance, because instance disks are erased. Optional Workspace/storage features in the current service API do not automatically back up instance disks. Service eligibility, terms, prices, model/dataset rights and third-party licenses apply separately from the MIT instructions.

The README's optional unpinned cloudgpu-mcp npm package is external to this repository and was not installed or audited. Inspect and pin that package before using it with credentials. This review does not clear the MCP package, GPU images, custom nodes, models or workload code.
