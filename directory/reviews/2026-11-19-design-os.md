## Bounded security and evidence notes

The designer build helper copies the page folder into a new evidence directory, refuses an existing output destination, filters dotfiles and node_modules, rejects nested symlinks, caps file count/size and records hashes. Keep unrelated private files outside the selected page folder. Screenshot inspection renders local JavaScript; it is not inert document parsing. The helper blocks nonlocal requests and marks unavailable WebSocket interception incomplete. These are source observations, not a sandbox guarantee or runtime result.

Read-only inspection covered the two SKILL.md files, LICENSE, package.json and selected designer helpers.
