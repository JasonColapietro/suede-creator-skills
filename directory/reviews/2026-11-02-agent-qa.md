## What it does

agent-qa runs natural-language QA tests: a user describes a journey in plain language, and agent-qa tests it on web, Android or iOS and keeps the evidence from the run. It works from the CLI, from its dashboard, and from a coding agent through its MCP tools and skills. Its memidex memory keeps facts and working procedures as reviewable files in the user's repository, and its self-improvement loop validates lessons from runs.

The repository bundles four agent skills at `skills/`, mirrored at `packages/cli/skills/`:

- `agent-qa-authoring`: create, edit, validate and run tests, suites and hooks.
- `agent-qa-result-triage`: investigate failed runs, inspect artifacts and classify failures.
- `agent-qa-knowledge`: read runs, evidence and stored knowledge through the MCP tools or the CLI.
- `agent-qa-debug-fix`: debug, patch and verify a failed run from its evidence.

## Setup facts

agent-qa requires Node.js 24 or later. Install it with `npm install -D agent-qa`, run `npx agent-qa init`, then follow the [quickstart](https://vostride.com/docs/agent-qa/quickstart) to connect a model and run the demo. Runs use the model provider the user connects.
