## Installation and dependencies

The README documents `npx skills add appierun/appie-mcp`. The directory publishes
its established skill-folder installation commands for each accepted skill and
omits the whole-repository installation shortcut because it could include
unrequested skills. Shell quoting and branch handling remain unchanged.

These are instruction-only skills with no bundled scripts, executables, or
hooks. Their workflows require a user-owned Appie project and a connection to
the hosted MCP endpoint at `https://appie.run/mcp`. Article topics and author
samples, chatbot training sources and messages, and destination URLs are sent
to that service by their respective workflows. Installing SKILL.md alone does
not provide the service or credits. Directory summaries state the hosted MCP,
API-key, and credit requirements.

The three SKILL.md files require an Appie project API key in the Authorization
header and explicitly prohibit asking users to paste the key into chat. The
repository's `.mcp.json` references the `APPIE_API_KEY` environment variable;
README examples use placeholders and say never to commit a real key.
`server.json` marks the required Authorization header as secret. No live key
was present in the inspected configuration or skill files.

Credit costs above agree with the [publisher's public MCP reference](https://appie.run/docs/mcp)
as read on the review date. The review does not repeat the free-signup offer or
infer that every supporting write/training operation is free: the README
defers some of those operations to the service documentation.

## Listing and security checks

The accepted workflows do not automate social-platform posting or accounts,
bypass access controls or CAPTCHAs, or scrape people's personal data. The
chatbot's URL/sitemap ingestion is a knowledge-input feature of the publisher's
own service. The requested skills pass the directory's content, privacy, and
listing-policy filters; these filters and the normal grade thresholds remain
in force after the allowlist.

The review reads source files and public documentation only. It does not
install the third-party skills, execute their instructions, connect to their
MCP server, read user credentials, or spend credits. Structural grade A is the
published directory grade, not a hosted-service security or runtime certification.
