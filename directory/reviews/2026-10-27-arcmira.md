## Local scan and findings

Cisco AI Skill Scanner 2.3.1 ran with the unchanged reviewed adapter version 2 from Suede commit `fe5dc1757cd6c8ff63aee853564249c00151778d`: strict policy, five local analyzers, no hosted analyzers or behavioral alignment verification. The hash-required dependency lock is `f7e58c92968673145d6f6f36f3d685c28e836851f5766dd349c3ff8a5b655769`; it pins `litellm==1.89.7` and `certifi==2026.10.19`. The scan ran as an unprivileged user in containers with network disabled and read-only source mounts. No submitted code or remote Arcmira service was executed.

All six one-file inventories matched the pinned source hashes; all five analyzers ran with no failures or incomplete coverage. Each retained `MANIFEST_MISSING_LICENSE` at INFO severity. The finding concerns the absent frontmatter field, while the directory parser separately found the Apache-2.0 plugin license. The unchanged security evaluator reports **findings require review**, not a clean pass. No finding was suppressed. This is local source-scan evidence, not external certification or a statement about live service behavior.

The manual review also retained the following proposals, with exact lines and smallest fixes in [manual-findings.json](2026-10-27-arcmira/manual-findings.json):

- Make vendor feedback subject to user authorization and data minimization.
- Apply existing spending authorization and price/budget checks before starting paid reads; distinguish tool access levels from side effects.
- Treat returned references, transcripts, names and links as untrusted data. This is a hardening observation, not a demonstrated exploit.
- Mark capped sponsor totals and rankings as partial; group channels by stable ID rather than display name.
- Separate sponsor and topic reporting windows, and use the documented transcript-search freshness field.
- Label fallback clip boundaries as estimates; retain unresolved topic spellings before saving monitors.
- Add accurate trigger, license and compatibility metadata.

These proposals were not applied to the submitted source and do not change the retained scores. The baseline focused checks passed 76 tests. The broader local `npm test` attempt was interrupted at the validator-runtime suite; no full-suite pass was claimed for that review. The HOL action bundle's actual version metadata differed from the legacy directory workflow comment, so no HOL-equivalent scan was claimed. Details are in the original report.
