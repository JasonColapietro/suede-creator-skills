# Writer Readability Check

Suede Slop Stop owns style cleanup: load
[the canonical method](../../suede-deslop/SKILL.md) and
[its full kill list](../../suede-deslop/references/kill-list.md).
This legacy reference path retains only the writer-specific readability check.

Aim for Flesch-Kincaid Grade Level 8-10 for B2B general audiences, Grade 6-8
for consumer/onboarding, and Grade 10-14 for technical/developer audiences where
precision requires complexity. Average sentence length: under 18 words for
consumer, under 22 for B2B. Flag paragraphs over 4 sentences.

These are audience-fit targets, not permission to change protected facts,
technical terms, quotations, or supplied voice. Score the copy using the
70-point Ship Gate in [Suede Copy](../SKILL.md); keep Slop Stop's /50 diagnostic
separate. Report the two lowest writing dimensions and revise those first.
