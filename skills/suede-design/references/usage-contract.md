# Worked contract: Suede AI Design Skills

This is an illustrative application, not a claim of measured customer results.

## Input

Restyle an existing dashboard with supplied tokens and desktop/mobile screenshots. The primary task is reviewing overdue invoices; the logo is protected.

## Expected output

Inspect the current UI, choose a direction, revise hierarchy and spacing, and render both viewports. Return changed files, token decisions and a visual QA report covering the invoice state, loading, empty and error states. Preserve the supplied logo asset.

## Failure and validation

If the project does not build, report the exact command and error and distinguish source changes from rendered proof. Check contrast and keyboard focus, and compare the actual implementation to the reference instead of claiming success from a mockup alone.
